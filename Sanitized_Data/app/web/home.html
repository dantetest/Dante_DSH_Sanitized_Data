它能做什么

不是简单打码，是把「文件 → 大模型」这一段完整接管

01 / 识别

扫描件也能读

PDF、Word、Excel、图片、TIF 正射影像。没有文本层的扫描件自动走离线 OCR，逐页上报进度，随时可停。

02 / 视觉

公章与手写

OCR 读不出红色印章和连笔签名，改用图像特征识别：红章直接涂黑，落款签署区整块盖住，手写标为待确认。

03 / 双轨

两个出口

给 AI 读的换名版（映射加密留在本机，可还原）；给人看的涂黑版（破坏性重写，不可还原）。

04 / 自检

出口前再过一遍

导出后对成品重新解析、重新检测，原文还在就拒绝交付。审计日志带签名链，改一条后续全废。

支持的格式

解析器是插件式的，新增格式不用改管线

PDF（文本层 / 扫描件） Word .docx Excel .xlsx 图片 .png / .jpg（OCR） TIF 正射影像（剥离地理标签） 纯文本 .txt / .md / .csv / .log 三维 .obj / .ply / .glb / .stl

三个入口

本机跑引擎，浏览器做界面，Agent 走 MCP —— 同一个内核
