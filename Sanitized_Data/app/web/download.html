启动并打开控制台

# 安装包 / 绿色版：启动后自动打开浏览器

默认地址 http://127.0.0.1:8760/console，启动后会自动打开浏览器。 拖入文件即可开始。

服务器部署

源码仓库自带 deploy/sanitized-data.service 与 deploy/nginx.conf（源码包已下架，内部部署请从仓库获取）

SYSTEMD

开机自启

sudo cp deploy/sanitized-data.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now sanitized-data
systemctl status sanitized-data
NGINX

HTTPS 反代

关键是把真实域名透传给后端，否则同源校验会判定为跨站：

proxy_set_header Host              $http_host;
proxy_set_header X-Forwarded-Host  $host;
client_max_body_size 512m;
对外服务时请用 ./start.sh --host 127.0.0.1 只监听本机，由 nginx 提供 HTTPS； 不要把引擎直接暴露在公网。
