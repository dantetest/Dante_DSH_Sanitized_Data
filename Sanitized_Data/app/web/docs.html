数据隐站怎么用

从安装到两个出口、从本地还原到 MCP 接入。先看这一页，再按场景进入细分页。

1. 安装与启动

Windows 10/11 下载安装包，安装后从开始菜单启动。首次可开一次性 3 天全功能试用；处理引擎在本机运行，文件不上传。

2. 导入文件

支持 PDF（含离线 OCR）、Word .docx、Excel .xlsx/.xlsm、图片、正射 TIF、TXT/CSV/TSV，以及 OBJ/PLY/GLB/STL 的有限清理。导入后先看识别结果，再决定接受、替换或保留。

3. 两个出口

换名版
给 AI 读。敏感身份替换成可本地还原的假名，保留金额、日期、条款结构；真名和映射不出本机。
涂黑版
给人看。破坏性重写，删除文本层，不可还原；适合对外提交、归档、给非授权方。
换名版不是把真名发给 AI 再还原。AI 全程只读换名版；结果回到本机后，才用本机映射做本地还原。

4. 本地还原

换名版导出后，本机会保存映射。AI 处理完的结果拿回来后，在本机执行还原；还原报告可能含真值，不要回传云端。

5. MCP 接入

安装版/试用授权下可使用本地 stdio MCP，共 16 个工具，覆盖文档脱敏、文本脱敏、实体复核、导出、审计校验、还原等。接入 Claude Desktop、Cursor、Cline 或自定义 Agent 时，MCP 只连本机。

6. API 与边界

本机 API 只监听本机，供桌面工作台调用；不是公网服务。不承诺 100% 检出，不承诺合规/PIPL；重要文件必须人工复核。涂黑版不可还原；换名版映射库要保管好。
