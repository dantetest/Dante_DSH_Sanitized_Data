# 支持矩阵与能力口径（v1.1.0）

> 口径基准：**v1.1.0**（代码基线 `7c553ab` + 版本号升级；2026-10-21）
> 用途：对内施工/QA、对外文档/销售的统一口径。**与代码不一致时以代码和门禁测试为准**，并回头修本表。
> 判定三档：

| 档位 | 含义 |
|---|---|
| **自动** | 默认直接处理，导出后对成品复检；检出失败/残留会 warning 或阻断导出 |
| **待确认** | 默认只检出、不直接改（进「待确认」清单，用户确认后才处理） |
| **不支持** | 无该能力，**不对外承诺**；用人工框选/整图涂黑/转换格式兜底 |

## 1. 文件格式

| 格式 / 扩展名 | 解析 | 自动处理 | 待确认 / 条件 | 不支持 / 边界 |
|---|---|---|---|---|
| **PDF（文本层）** `.pdf` | ✓ | 文本/表格实体涂黑或换名（`apply_redactions` 真删除）；附件/批注/表单/JS 默认剥离；面积 ≥5% 的内嵌图片做视觉 + 印刷体文字规则扫描 | 低置信实体；`keep_pdf_hidden=true` 显式保留附件（写 warning） | 图片内手写/艺术字；旋转页/同页 >8 图/异常格式建议人工复核 |
| **PDF（扫描件）** `.pdf` | ✓ OCR | 先 OCR 再走文本规则；页面图像过人脸/证件/车牌/码类扫描 | 低置信实体 | 手写体、低分辨率扫描不承诺；单页 OCR 约 2.1 秒（PP-OCRv6） |
| **Word** `.docx` | ✓ | 正文/表格实体；清修订/批注/作者；内嵌图片自动扫视觉/码类 + 印刷体文字规则并回写 | 图表/文本框/OLE/activeX 等隐藏对象导出前确认 | XFA/SmartArt/SVG 文本未专门处理；无命中图片保留（可能仍带 EXIF/GPS） |
| **Excel** `.xlsx/.xlsm` | ✓ | 单元格实体；表头列级 + 纯数值金额（写回数字）；清隐藏表/定义名/批注；内嵌图片自动脱敏 | 图表/OLE 等隐藏对象导出前确认 | `.xlsm` 导出后不保留宏（告警） |
| **图片** `.jpg/.jpeg/.png/.bmp/.webp` | ✓ OCR | 文本规则；人脸/证件/二维码条码/红章/签署区/微信式聊天截图；重编码并剥离 EXIF/GPS；按 Orientation 转正 | 车牌；门牌/路牌/店招/单位铭牌；手写签名/手写批注 | 窗外景观/镜面反光/指纹/虹膜等无法自动识别；手写文字 OCR 不承诺 |
| **正射 TIF** `.tif/.tiff` | ✓ | 地理标签/sidecar/元数据剥离；LOCAL_CS 坐标中性化（默认）；图面文字与视觉目标扫描打码；Pillow 路径按 Orientation 转正；大图/16bit/多波段窗口化处理 | — | rasterio 大图路径不转正 Orientation（warning）；多帧 TIFF 只剥离不中性化；详见 §4 |
| **纯文本** `.txt/.md/.log/.json` | ✓ | 规则包文本实体 | 低置信实体 | 二进制内容不识别 |
| **CSV / TSV** `.csv/.tsv` | ✓ | 表头列级脱敏（两级/合并表头继承）；导出保持原分隔符/引号/列数、原编码/BOM/换行 | 低置信实体 | 无表头退化为普通规则；同文件上下堆叠多表只按最前面的表头处理 |
| **三维** `.obj/.ply/.glb/.stl` | ✓ 文本 | **仅**注释/名称等文本清理 + OBJ/PLY 顶点平移（GLB 仅 JSON 等长覆盖、STL 头置零） | — | 几何重定位仅 OBJ/PLY；贴图/MTL/内嵌图/OSGB/3D Tiles/LAS-LAZ/结构化 verify/预览均不支持，详见 §3 |
| **老版 Office** `.doc/.xls/.ppt` | ✗ | — | — | 不支持，请先「另存为」`.docx/.xlsx/.pptx`（`.pptx` 亦不在解析器范围） |
| **压缩包** `.zip/.7z/.rar` | ✗ | — | — | 不支持整包处理；请解压后逐文件处理（三维整包目录同理） |
| **其它未列格式** | ✗ | — | — | 不支持（`.heic/.psd/.tga` 等；先转换为支持格式） |

> 说明：`.pptx` 目前没有解析器；Office 系只覆盖 Word（docx）与 Excel（xlsx/xlsm）。

## 2. 敏感目标 / 场景口径

| 目标 / 场景 | 档位 | 说明 |
|---|---|---|
| 文本类实体（姓名/证件号/手机号/地址/账号/金额/案号/病历号/快递单号/车次座位/VIN/IMEI/SN/MAC/IP 等） | **自动** | 规则包热加载（common / finance-cn / legal-cn / medical-cn / trade-cn / geo-cn / pipl-cn / table-cn）；导出后成品复检，原文残留即拦截 |
| 文件元数据（作者/设备/GPS/EXIF/XMP/ICC/PDF 隐藏数据） | **自动** | 导出时破坏性清理；PDF 附件/批注/表单/JS 默认剥离 |
| 人脸 | **自动** | 正脸 + 条件侧脸；涂黑范围为整个头；长边 >1600 自动分块。缩放漏检时提示人工复核，不承诺 100% 召回 |
| 证件（11 类） | **自动** | 身份证默认「关键字段」档（正面头像/姓名/号/住址，反面签发机关/有效期）；其他证件整卡/整区域；字段定位失败回退整卡 |
| 二维码 / 条形码 | **自动** | 10 种码制，默认一律打码、不保存解码内容；`/detect` 低置信候选（面积 >5% 页面）仅提示不自动打码 |
| 红色公章 / 签署区 | **自动** | 颜色特征 + 版面标签识别后整块涂黑 |
| 车牌 | **待确认** | OCR 正则 + 完整牌面色块（蓝/绿/黄底）；检测不到文字时回退 OCR 框并提示 |
| 门牌 / 路牌 / 店招 / 单位铭牌 | **待确认** | OCR 可读时识别牌面区域并进确认清单；无 OCR/白底/竖排手写/远距小字不承诺 |
| 手写签名 / 手写批注 | **待确认** | 墨迹团块/低置信短行检测，误报率原因不自动改 |
| 微信式聊天截图 | **自动** | 逐项涂黑头像/昵称/群名/状态栏时间/输入框；仅图片 + OCR 文本 |
| 未成年人提示 | **自动提示** | 从身份证生日推断 <14 → 红色提示；人工开启严格模式后才强制整卡；**不做人脸年龄估计** |
| 精确时间模糊化 | **手动（默认关）** | 投放开关；只处理「完整日期 + 时刻」 |
| 组合风险提示 | **自动提示（不自动改）** | 同一媒体 ≥2 类准标识符时黄色提示 + 一键整图涂黑 |
| 窗外景观 / 室内装修 / 镜面反光 / 指纹 / 虹膜 | **不支持自动** | 用对照台「⊘ 整图涂黑」或框选补漏兜底；不承诺自动识别 |
| YuNet 侧脸模型 | **未随包** | WIDER FACE 许可（CC BY-NC-ND）未商用确认；侧脸/低头/极小脸漏检风险 |

## 3. 三维域口径（综合完成度 ≈ 20%）

**一句话**：只覆盖 4 种桌面中间格式的文本/注释清理与 OBJ/PLY 顶点平移；**无人机倾斜摄影主产物（OSGB / 3D Tiles / LAS-LAZ）与贴图为 0，不承诺真实倾斜摄影交付**。

| 能力项 | 档位 | 说明 |
|---|---|---|
| OBJ 注释 / `o/g/usemtl` 名称 / `mtllib` 引用文本清理 | **自动** | 流式两遍扫描重写；`mtllib` 行仅为文本清理，不读取 `.mtl` 文件 |
| OBJ 顶点平移（包围盒中心 → 原点） | **自动** | 测量/工程大坐标模型；无法重定位时 warning |
| PLY header `comment` / `obj_info` 清理 | **自动** | ASCII 文本替换；二进制整行删除（不改写变长内容） |
| PLY 顶点平移 / 数据段等长 / 成品结构自检 | **自动** | P0 修复；成品复检失败删除成品并 `ExportError`（不再复制源文件） |
| STL 80 字节头（作者/文件名/构建时间） | **自动** | 命中敏感串时头置零；几何原样透传 |
| GLB JSON 文本（`asset.copyright` / `extras` / `object.name` 等） | **自动** | **仅等字节长度覆盖**（保 chunk 长度）；几何 BIN 原样 |
| GLB / STL 几何坐标平移 | **不支持** | 明确 warning「暂不支持几何重定位」 |
| 贴图 / 内嵌照片 / 三维文件内 EXIF、GPS | **不支持** | GLB 内嵌图、OSGB 内嵌 JPEG 均未解析 |
| MTL 材质文件 | **不支持** | 只清理 OBJ 里的引用文本，不处理材质文件本身 |
| OSGB 分块倾斜模型（Data/Tile_*.osgb + metadata.xml） | **不支持** | 能力为 0；元数据原点/瓦片坐标/内嵌贴图均未处理 |
| 3D Tiles（tileset.json / b3dm / transform） | **不支持** | 能力为 0；JSON 仅可能作为纯文本被处理，无结构语义 |
| LAS / LAZ 点云 | **不支持** | 无 laspy/lazrs 依赖，能力为 0 |
| 三维结构化 verify | **不支持**（PLY 除外） | `.ply` 有 parser 导出后结构自检（顶点/面比对）；`pipeline.verify` 对 mesh 仍只重读 header 文本 |
| 三维几何预览 | **不支持** | 无三维渲染/坐标预览；控制台只呈现文本清单与页面 |
| 综合完成度 | **≈ 20%** | 按真实交付格式加权（OSGB/3D Tiles/LAS/贴图全为 0 后下调）；不建议对测绘客户宣传"支持倾斜摄影" |

> 依据：[impl/mesh.md](impl/mesh.md)、[research/03-三维倾斜摄影与正射TIF脱敏进度与方案.md](research/03-三维倾斜摄影与正射TIF脱敏进度与方案.md)、[research/11-三维与正射脱敏专项调研.md](research/11-三维与正射脱敏专项调研.md)。

## 4. 正射 TIF 域口径

| 能力项 | 档位 | 说明 |
|---|---|---|
| 地理标签剥离（GeoTIFF 33550/33922/34264/34735/34736/34737 等 + EXIF/GPS/XMP/ICC/IPTC） | **自动** | 成品再扫一遍，真实 CRS/tiepoint/ICC/EXIF 残留即 `ExportError` |
| sidecar 清理（`.tfw/.prj/.aux.xml/.ovr/.kml/.rpc/.rpb/.imd/.xml`） | **自动** | 删除成品派生 sidecar（不碰源文件）；删除失败 warning |
| 坐标中性化 v1（随机平移 + 旋转，写 LOCAL_CS；参数可逆） | **自动（默认）** | `YINZHAN_TIFF_GEO_MODE=neutralized`；参数入 `geo_params`，AI 换名模式写加密映射库；human 模式不保存参数（不可还原） |
| 彻底去参考 `strip` 模式 | **自动（可配）** | `YINZHAN_TIFF_GEO_MODE=strip`；不写 CRS/transform，坐标不可还原 |
| 图面文字 / 视觉目标打码 | **自动** | 与图片管线同一套 OCR 规则 + 人脸/证件/车牌/码类扫描；大图先降采样扫描（warning 可能漏检条码类） |
| 大图 / 16bit / 多波段 | **自动** | rasterio 窗口化重绘、保留 dtype/波段、内部金字塔；20000×20000（4 亿像素）实测解析 4.7s、导出 7.0s、峰值约 1016 MB |
| Pillow 路径 Orientation 转正 | **自动** | P0 已修：parse/render/export 按 tag 274 转正，成品不再写 274 |
| rasterio 大图路径 Orientation 转正 | **不支持** | 保持原始像素朝向 + 明确 warning（P1 限制）；需方向正确时先转正源图或强制 Pillow 路径 |
| 多帧 TIFF 坐标中性化 | **不支持** | Pillow 回退只剥离/清元数据，不中性化（明确 warning） |
| 无文字、只有地理标签的影像「只清理」导出 | **自动** | P0 已支持（`has_cleanup_targets` 允许只清理导出） |
| 合规语义 | — | 只做「降密」：坐标移了，河流道路形状/纹理仍可能反推；不承诺匿名化 |

> 依据：[impl/tiff.md](impl/tiff.md)、[research/03-三维倾斜摄影与正射TIF脱敏进度与方案.md](research/03-三维倾斜摄影与正射TIF脱敏进度与方案.md)。

## 6. 对外表述口径（能说 / 不能说）

**可以说**

- 「本机处理、不联网、导出为破坏性重写并做成品复检」
- 「支持 PDF/Word/Excel/图片/TIF/文本/CSV/TSV 的脱敏；三维支持 OBJ/PLY/GLB/STL 的有限文本清理与 OBJ/PLY 顶点平移」
- 「正射 TIF 可剥离地理标签并做 LOCAL_CS 坐标中性化；方向标签（Orientation）已修复」
- 「去标识化不等于匿名化，本产品只承诺『已隐去』，不承诺『已合规』」

**不能说**

| 禁止表述 | 原因 |
|---|---|
| 「支持倾斜摄影 / OSGB / 3D Tiles / LAS 脱敏」 | 三维主产物能力为 0；仅 4 种中间格式有限清理（≈20%） |
| 「贴图/材质已处理」「三维坐标已完全清理」 | 贴图/MTL/GLB 内嵌图未处理；GLB/STL 不做几何平移 |
| 「100% 识别 / 零漏检」 | 人脸侧脸、手写、低质量扫描均有漏检边界 |
| 「满足《个人信息保护法》/已匿名化」 | 去标识化数据在国标语境下仍属个人信息 |
| 「坐标完全不可还原」 | `neutralized` 参数可逆（AI 模式存加密映射库）；只有 `strip` 模式不可还原 |
| 「PDF 附件已清理所以一定安全」 | `keep_pdf_hidden=true` 可显式保留；保留时依赖用户知情与出口自检 |
