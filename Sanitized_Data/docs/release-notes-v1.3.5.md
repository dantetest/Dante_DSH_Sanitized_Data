## 本版重点

> **密钥轮换（2026-11-04）**：生产签发密钥新增 `prod-2026b`；安装包 `public_keys.json` 同时保留 `prod-2026`，旧授权继续有效。新私钥/新口令部署见 `docs/ops/生产License密钥部署手册.md`。

本版完成 L3「扫码支付 → 自动签发 → 本机自动导入解锁」的真实支付宝联调，并收口购买/价格/授权页。

### 1. 本机购买页 + 自动解锁

- 新增 `/purchase` 页面：读取本机识别码 → 选择版本 → 支付宝扫码 → 轮询订单 → 支付成功后自动导入授权并解锁。
- 支付回调不可达时，商业服务通过 `alipay.trade.query` 主动查单兜底。
- 授权签发绑定本机识别码，授权文件不上传、不联网核验。
- **已授权用户不再显示购买入口**：购买页和授权页在 `paid` 状态下隐藏选择版本、支付宝扫码、价格/续费入口，只保留当前授权和进入控制台/授权详情操作。

### 2. 价格页收敛

- 价格页只保留 **个人版 ¥199/年** 一档，移除免费版/专业版/团队版/机构版/早鸟价展示。
- 价格页重新排版为「左侧说明 + 右侧价格卡 + 购买流程 + FAQ」。

### 3. 授权页重排

- 当前授权与升级/续费左右并列；导入授权改为拖拽/粘贴双栏；FAQ 与本机授权事件并列。
- 授权页价格同步只展示 ¥199。

  - ICP 备案号：蜀ICP备19033433号
  - 增值电信业务经营许可证：川B2-20261782

### 5. 订单找回 / 授权码补取

- 商业服务已有订单页：`/order.html?order_no=...&token=...`，支持查状态、复制授权码、下载 `license.json`。
- 本机购买页新增「最近订单 / 找回授权」卡片：下单后把订单号+查询令牌保存在本机浏览器 localStorage；支付成功但自动导入失败、或关闭页面后再回来，可点「查看订单 / 授权码」补取。
- 查询令牌等同取货凭证，页面提示不要转发；清除记录按钮可删除本机保存。
