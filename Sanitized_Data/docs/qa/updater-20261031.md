# 客户端一键更新（2026-10-31）

> 目标：界面提示有更新 → 用户点击 → 下载绿色版更新包 → 校验 → 关闭程序 → 替换文件 → 重启。
> **不静默安装、不静默下载**；只有用户点按钮才下载/安装。

## 1. 已实现

| 能力 | 位置 | 说明 |
|---|---|---|
| 检查 manifest | `app/server/yinzhan/updater.py` | CKA `/updates/latest.json`，短超时；只读 version/assets |
| 版本比较 | `updater._is_newer` | 只有远端版本更高才提示 |
| 下载 | `UpdateManager.start_download` | 后台线程，进度；`.part`；大小/SHA-256 校验 |
| 安装 | `UpdateManager.install` | **绿色版 zip 自替换**：helper 等待/终止旧进程，解压覆盖安装目录，重启 |
| 安全 | 校验 SHA-256/大小 | 不通过则删除，不执行 |
| API | `/api/update/check`、`/download`、`/status`、`/install` | 同源本地接口 |
| UI | 顶栏「检查更新」+ 更新弹窗 | 自动检查一次；「立即更新」才下载；「稍后」24h |
| 设置 | `localStorage: yz_update_later_until` | 24h 内不再自动提示 |

## 2. 用户流程

1. 启动后约 4 秒检查一次；有更新弹窗「发现新版本」；
2. 用户点「立即更新」→ 下载并显示进度；
3. 下载完成 → 按钮变「安装并重启」；
4. 点击 → helper 关闭旧进程 → 解压覆盖 → 启动新版；
5. 「稍后」→ 24 小时内不再自动提示，仍可手动检查。

## 3. 为什么用绿色版 zip

当前 Inno 安装器在部分机器上启动失败（已实测），因此一键更新**不依赖安装器**：

- 更新包用 CKA 上的 `windows_portable` 资产；
- 更新 helper 先退出旧进程，再解压覆盖程序目录；
- 用户数据在独立数据目录，不会被覆盖；
- 初始安装仍可用「绿色版 + 一键安装 .cmd」。

## 6. 边界

- 只有 HTTPS/HTTP + SHA-256 通过才执行；
- 不替换用户数据目录；
- 更新后首次启动仍是正常启动检查；
- 如果 helper 失败，会尝试重新启动旧程序并写 `updates/update.log`。
