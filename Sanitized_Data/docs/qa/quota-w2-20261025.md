# 免费额度 W2 实现与自测（2026-10-25）

> 范围：P1 W2「免费额度与前置拦截」后端核心。目标：免费用户 3 份/天、单份 ≤20 页、
> TIF/3D 禁用、单文件 ≤100MB、只允许通用规则包；非法请求在建任务前拒绝。
> 不含 W3 授权 UI/状态条/弹窗，也不含 MCP 文件工具的完整功能位门禁。

## 1. 已实现

| 功能 | 位置 | 行为 |
|---|---|---|
| 开关 | `quota.is_enforced()` | 源码默认关闭；PyInstaller 打包后默认开启；`YINZHAN_ENFORCE_FREE_TIER=1` 可在源码验收 |
| 格式 | `quota.precheck()` | 免费版禁止 `tiff/mesh`（含 `.tif/.tiff/.obj/.ply/.glb/.stl`） |
| 大小 | `quota.precheck()` | 免费版单文件 ≤100MB |
| 页数 | 预判 PDF/图片；解析后统一检查 | >20 页拒绝；Office 在解析后 `quota.after_parse()` 检查并退额度 |
| 规则包 | `quota.precheck()` / `visible_packs()` | 免费只允许 `common`；付费包直接 `pack_requires_paid`，不静默过滤 |
| 每日额度 | `LicenseService.quota_status/consume_free_job/refund_free_job()` | 本地自然日 3 份；跨日重置；时钟回拨不重置 |
| 并发 | `JobManager.active_free_count()` | 免费同一时刻仅 1 个未完成任务 |
| 退出/退还 | `JobManager._run` | detect 前解析/系统失败退 1 份；用户取消不退；页数/OCR 超限退额度 |
| API | `/api/license/status`、`/api/quota/status` | 返回剩余额度；license status 里带 `quota` 字段 |
| API packs | `/api/packs`、`/api/health` | 免费只暴露 `common` |
| 任务创建 | `api.create_job` + `JobManager.create` | API 预检 + Manager 兜底，双重防止绕过 HTTP |

## 2. 错误码

`quota_exceeded`、`free_page_limit`、`free_ocr_limit`、`free_format`、
`free_size_limit`、`pack_requires_paid`、`quota_busy`。

  - 前 3 个任务 200；

- MCP 门禁手工验证：free 下 `list_rules/check_support/redact_text` 可用；
  `sanitize_file` 返回 `license_required`；trial 后可调用。

## 4. 设计取舍/未做

1. **OCR 页数**：PDF 扫描页与单图已在 `doc.meta["ocr_pages"]` 回填，`after_parse`
   对 >10 页直接拒绝并退额度；Office 内嵌图片 OCR 暂未计入（其页数上限仍受 20 页/份约束）。
2. **MCP 文件工具**：`mcp_server` 已加功能位门禁：`list_rules` / `check_support` /
   `redact_text` 始终免费；文件写/复核/导出等需要 `mcp` 功能位（Pro/试用），否则返回
   `license_required`。源码模式未启用，打包版启用。
3. **源码模式不启用**：避免破坏现有 33 个功能域测试；打包版自动启用；
   发版前用 `YINZHAN_ENFORCE_FREE_TIER=1` 做验收。
4. **UI**：状态条、升级弹窗、`/license` 页是 W3。

## 5. 复现

```powershell
python -X utf8 app/tests/test_quota.py
$env:YINZHAN_ENFORCE_FREE_TIER='1'
python -X utf8 app/server/run.py --no-browser
# 另开终端
curl http://127.0.0.1:8760/api/quota/status
```
