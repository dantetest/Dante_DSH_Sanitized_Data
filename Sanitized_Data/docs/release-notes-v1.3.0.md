# 数据隐站 v1.3.0 发布说明（收费能力首发）

> 版本：**v1.3.0** · 2026-10-25
> 定位：在免费版基础上加入离线授权、免费额度、授权页/价格页、人工签发闭环；**不做**自动支付。

## 一、本版重点

### 1. 离线授权（W1）
- Ed25519 签名 `license.json`，本机公钥验签；
- 机器码绑定（Windows/macOS/Linux）；
- 14 天全功能试用；
- 年度/买断、到期 + 14 天宽限；
- 时钟回拨检测、状态文件 HMAC、本地授权事件；
- `/license` 页面导入/备份授权。

### 2. 免费额度（W2）
- 每天 3 份；
- 单份 ≤20 页；
- 扫描件 ≤10 OCR 页；
- 单文件 ≤100MB；
- TIF/三维格式仅付费；
- 免费只开放通用规则包；
- 免费任务串行；
- 被拒/解析失败按规则退还额度。

### 3. 授权 UI 与价格页（W3）
- 控制台顶部状态条；
- 额度/格式/规则包拦截弹窗；
- `/license` 授权档案卡；
- `/pricing` 价格页；
- 购买入口 A：`YINZHAN_PURCHASE_URL` 可配置，链接带机器码。

### 4. 人工签发（W4a）
- `deploy/license_issue.py` 签发 CLI；
- 个人/专业/团队/机构、年度/买断；
- 订单台账模板、人工交付手册。

## 二、测试构建说明（重要）

本仓库同时支持两种构建：

| 构建 | PAYWALL_ENABLED | 用途 |
|---|---|---|
| **TestMode 测试构建** | `False` | 给朋友/内测：全功能，不弹收费限制，不卡 3 份/天 |
| **正式构建** | `True` | 公开收费版：W2 免费额度 + W3 升级入口生效 |

测试构建命令（仅内部）：

```powershell
powershell -ExecutionPolicy Bypass -File desktop\build_win.ps1 -TestMode
```

测试构建会写临时的 `app/server/yinzhan/_build_flags.py`，打包完成后自动删除。
**测试构建不要公开发布**，正式 v1.3.0 用不带 `-TestMode` 的构建。

## 三、已知限制

1. **生产公钥已生成并合并**：key_id=`prod-2026`；正式包已内嵌生产公钥。测试构建曾使用测试公钥，测试包不对外发布。
2. **购买入口 URL 尚未配置**：`/pricing` 显示参考价；配置 `YINZHAN_PURCHASE_URL` 后才打开购买页。
3. **无自动支付/自动开票**：微信/支付宝、回调、订单后台、退款/发票自动化属于 W4b，等 ICP/商户号。
4. **未做代码签名/Apple 公证**：SmartScreen 可能提示未知发布者；按既定决策等真流水后补签。
5. **本版发布说明先覆盖 Windows**；macOS v1.3.0 构建另排。
6. 静态购买二维码由购买平台生成，产品不加载外部二维码服务。
