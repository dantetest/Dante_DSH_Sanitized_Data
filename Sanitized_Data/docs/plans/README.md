## 建议的首周执行顺序

1. **修 P0 缺陷**：二进制 PLY 损坏、TIF Orientation（已开任务，2.5–4 人日）。
2. **重建安装包**：PyInstaller + Inno Setup；断网/干净用户环境验收（2–3 人日）。
3. **真实文件回归**：判决书/身份证/Office 内嵌图/PDF/CSV + 5 个公开样本（2–3 人日）。
4. **口径收敛**：README/投放台/三维正射说明与实现一致（0.5 人日）。
5. 同时启动：ICP/商户/开票资质材料（用户侧）；盘点真实测试集缺口（用户侧）。
6. 稳定后再按 02 开商业化，按 03 评估三维。
