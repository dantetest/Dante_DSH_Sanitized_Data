# 02 · 商业化上线框架（ICP/商户资质到位后可直接开工）

> 状态：**框架规划（不改代码）** · 2026-10-20 · 依据：[09 定价调研](../research/09-市场定价调研与定价建议.md) + [商业化设计包](../impl/monetization.md)（licensing/free-tier/payment-invoice/pricing-page）
> 用户输入：ICP 正在取证；先把框架规划好，手续齐后直接上线收费功能。
> 硬约束：**引擎/安装包保持零外呼**；商业侧与产品侧物理分离；私钥不进仓库/安装包；Windows 先发。

---

## 0. 一句话架构

```
用户浏览器（公网）──▶ 商业站点（独立部署：价格页/购买/订单/支付回调/发票/授权签发）
       │                                   │
       │ 扫码/跳转支付                       │ 用户下载 license.json
       ▼                                   ▼
本机数据隐站（127.0.0.1，无出站）── 本地授权校验/免费限额/试用 ──▶ 脱敏引擎
```

**产品内不出现支付/激活/联网代码**；购买只在系统浏览器完成；授权文件离线导入。

## 2. 目标模块与文件骨架（实施时创建）

### 2.1 产品侧（本地，新增目录；不联网）

```
app/server/yinzhan/
  license/
    __init__.py
    machine.py          # 机器码 v1（CPU/主板/磁盘/OS 组合，稳定+容错）
    verifier.py         # Ed25519 验签 + 机器码 + 到期/宽限 + 时钟回拨检测
    state.py            # data/license/{license.json,state.json,trial.json} 原子读写
    features.py         # 功能开关：free/pro/team/org/seat
    trial.py            # 14 天试用（本地、防简单重置、审计）
    quota.py            # 免费版限额（份数/页数/OCR 页/MCP/批量/审计导出）
  api_license.py        # /api/license/import|status|machine_code（仅本地）
```
- 入口挂接：`api.upload` / `api.create_job` / `jobs.JobManager.create` / `mcp_server.py` 的 `sanitize_document` 都要过同一门禁（不能只靠 UI）。
- 审计：授权导入/试用开始/限额触发写入本地 `audit`（只记类型/数量，不记敏感值）。
- 公钥只读资源打进包；测试密钥只在测试环境，不进生产包。

### 2.2 商业侧（独立部署，不进安装包）

```
commercial/
  web/                 # 官网静态页/价格页/购买页（可复用 app/web 风格）
  server/              # FastAPI/Flask：订单、支付回调、授权签发、发票、管理后台
    orders.py
    payment_wechat.py
    payment_alipay.py
    licensing.py       # 调签名器；私钥权限 600，仅此服务器
    invoices.py
    admin.py
  signer/              # 离线签名器（CLI/库），与 server 分离
  db/                  # SQLite/Postgres schema+迁移
```
- 商品 SKU 单一事实来源：`commercial/skus.yaml`（个人/专业/团队/机构/按次），与 09 报告价格一致。
- 订单/授权/发票/对账表结构按 `docs/impl/payment-invoice.md`。
- 管理后台：订单查询、补发、绑定/解绑、退款、发票、报表、2FA。

## 3. 关键接口（产品 ↔ 商业，仅文件/浏览器交互）

| 交互 | 方式 | 说明 |
|---|---|---|
| 购买 | 本机价格页「购买」按钮 → 系统浏览器打开商业站点 | 产品不请求网络；链接可带机器码/版本参数（用户可复制） |
| 授权签发 | 商业站点生成 `license.json`，用户下载 | 可发邮件/下载；含订单号、机器码、到期、功能位、签名 |
| 本地导入 | `POST /api/license/import`（127.0.0.1） | 验签/机器码/到期；成功后解锁 |
| 状态查询 | `GET /api/license/status` | 免费/试用/已授权/宽限；UI 展示 |
| 免费限额 | `POST /api/jobs`、`/api/upload`、MCP 工具入口 | 超限返回固定错误码，前端展示升级提示 |
| 升级/补发 | 用户凭订单号+机器码在商业站点申请 | 人工/自动；审计 |

`license.json` 建议字段（详见 licensing.md）：`license_id, product, sku, seats, features[], machine_code, issued_at, expires_at, updates_until, order_id, nonce, sig`。签名用 Ed25519（cryptography 已是依赖）。

## 5. 安全与合规设计要点

- 引擎零外呼：不得在 `app/server/yinzhan/**` 出现支付/激活 HTTP 请求；CI/红线静态扫描。
- 私钥只在商业服务器/离线签名器；仓库 `.gitignore` 拒绝 `*.key`、`license_private*`；泄露轮换预案。
- 生产包只含公钥；测试授权用独立测试密钥，生产包不认。
- 防篡改尽力而为：本地冗余状态 + 时钟回拨检测 + 审计链；不承诺 100% 防破解（低价 + 更新服务降低动机）。
- 不采集遥测/文件内容；免费限额计数本地。
- 商业站点：支付回调验签、金额核对、幂等、限流、2FA、对账；不存卡信息。
- 隐私/协议：EULA、隐私政策、退款政策、发票说明；PIPL 定位仍是「去标识化工具」，不承诺合规。
- 老用户/内测：赠送 1 年个人版（决策 D4），免费版永久可用。

## 6. 验收（P0 商业化）

1. 免费版：限额生效、错误码正确、状态条显示；超限不产生半成品文件。
2. 试用：首次启动 14 天全功能；本地状态；重置有难度；审计记录。
3. 授权：测试密钥签发 → 导入成功/失败用例（错机器、过期、宽限、时钟回拨）；功能位生效；卸载重装保留本地授权。
4. 价格页：4 档 + 机构入口 + 购买外链；无外链脚本/CDN；移动端可用。
5. 支付/发票（资质后）：微信/支付宝链路、回调幂等、订单可查、授权自动/人工签发、普票/专票、退款、对账。
6. 安全：无出站网络；无私钥进包/仓库；审计链验证；测试授权不能在生产解锁。
7. 回归：免费限额不破坏现有 241 项红线；测试环境注入授权后全套绿。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| ICP/商户审批慢 | 先做 W2/W1/W3；过渡对公转账；不提前收款 |
| 测试环境被免费限额打破 CI | 测试注入测试授权；生产包不认测试密钥 |
| 热点文件冲突（api/jobs/app.js） | 新文件为主 + 薄 hook；每步 regression |
| 授权被破解/试用重置 | 低价 + 本地冗余 + 时钟检测 + 更新服务；不承诺绝对防破解 |
| 私钥泄露 | 服务器隔离/权限/备份/轮换/CI secret scanning |
| 价格页转化差 | 09 的验证计划先跑；早鸟限量；不轻易降价 |
