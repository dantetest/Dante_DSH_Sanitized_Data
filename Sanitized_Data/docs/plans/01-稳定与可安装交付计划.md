## 0. 完成定义（DoD）

1. Windows 安装包（Inno Setup）在**干净 Windows 10/11**（无 Python、无开发环境）安装成功；启动到首页/控制台；断网可用。
2. 5 个既有样例 + 用户真实测试集 + 5 个公开测试样本全部：解析成功、导出成功、`verify` residual=0、无崩溃。
3. `regression`（当前 241 项）与 `run_all`（14 套件）在**打包前源码**与**安装后程序内**各跑一次全绿（安装后至少跑 e2e/关键路径）；安装包不含密钥/测试授权/开发依赖。
4. P0 已知缺陷（PLY、TIF Orientation）修复并纳入回归；三维/正射对外口径与实现一致。
5. 卸载/升级路径验证：数据目录（`%LOCALAPPDATA%\Sanitized_Data`）保留/清理策略明确；旧版本升级不丢授权/映射库/审计链。
6. README、发布说明、已知限制、安装/卸载/排障说明齐全；版本号与 Git 提交可追溯。

## 1. 当前事实与缺口（2026-10-20 核对）

| 事实 | 影响 |
|---|---|
| 源码直接运行可用；`desktop/app.spec`、`desktop/installer.iss`、`build_win.ps1` 存在 | 具备打包基础，但 P1-A/P1-B/P1.5 后未重建 |
