## 1. 为什么是 B（同仓独立域模块），不是新项目

- 共享：UDM/管线/规则/检测/替换/映射库/审计/任务框架/图像扫描与 OCR 内核。
- 独立：入口/依赖/发布包/测试门禁/版本节奏；避免影响主产品稳定性。
- 只有出现测绘类客户/合同、真实 OSGB/3D Tiles 样例、合规条件明确时，才考虑独立仓库/项目。

## 2. 需要新增的 5 类抽象（B 的核心成本）

| # | 抽象 | 作用 | 关键接口/文件（建议） |
|---|---|---|---|
| A1 | **Package/Asset** | 一个模型/场景 = 多文件（模型+贴图+材质+元数据）；支持目录/ZIP/清单 | `scene/package.py`：`ScenePackage.open()`、`assets()`、`read/write` |
| A2 | **Scene/TileTree** | 3D Tiles/OSGB/GLB 场景与瓦片树；节点引用与变换 | `scene/tree.py`：`SceneNode`、`TileSet`、`traverse()` |
| A3 | **PointCloud** | LAS/LAZ/PLY 点云（分块、属性、CRS） | `scene/pointcloud.py`；可选依赖 laspy/lazrs |
| A4 | **结构化 Verify** | 不只看文本：检查几何/贴图/内嵌图/元数据/目录清单残留与一致性 | `scene/verify.py`；复用 pipeline.verify 钩子 |
| A5 | **Scene 预览/框选** | 最小资产对照视图（非完整 3D 引擎）；页面缩略/贴图列表/坐标框 | `app/web` + `render` 扩展；P1 可只做资产列表 |

配套：`parsers/mesh_package.py`（目录/压缩包入口）、`parsers/osgb.py`（后置）、`parsers/3dtiles.py`；UDM 扩展 `Asset/Scene` 或在 `Document.extra` 挂结构（需 CONTRACT v4）。

## 5. 验收与门禁（B 启动时写进 red-lines）

- 结构：场景/包目录清单完整、节点引用可解析、无丢失资产。
- 脱敏：文本/注释/贴图文字/内嵌图/元数据残留 0；贴图图像走既有人脸/码/文字管线；坐标/工程原点中性化（如适用）。
- 一致性：几何/顶点/面数与源文件一致（除显式重定位）；贴图引用完整。
- 失败阻断：解析/导出/verify 任一失败必须阻断，不允许「静默丢资产」。
- 样例：真实（脱敏/授权）+ 合成；OSGB/3D Tiles 至少各 1 真实样例，否则不承诺。
- 性能：大场景分块/内存上限；进度/取消可用。

## 6. 风险

| 风险 | 对策 |
|---|---|
| 需求不明确、样例缺失 | 先要真实样例/合同；无样例不立项 |
| 格式规范复杂（OSGB/3D Tiles） | 先 B2（OBJ/GLB），OSGB 触发制 |
| 贴图脱敏后模型不可用 | 贴图回写保持尺寸/格式；提供 strict/保留选项 |
| 依赖许可/体积 | 可选依赖评审；缺失降级 |
| 范围蔓延（完整 3D 预览） | 只做最小资产对照；完整预览单独立项 |
| 影响主产品稳定 | 同仓独立域 + 功能开关 + 独立测试/发布包 |
