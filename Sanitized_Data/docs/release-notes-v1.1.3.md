# 数据隐站 Sanitized_Data v1.1.3 发布说明

> 2026-10-22。本版聚焦「给 AI 看」换名版（mode=ai）的可读性、一致性与安全性；「给人看」涂黑版（mode=human）行为在 AI 专属修复上保持不变（逐页像素 diff=0 验收），检测规则增强属于两版共享的预期改进。

## 一、AI 视图导出修复（换名版）

| 项 | 说明 |
|---|---|
| 替换框与黑框相交泄漏 | 与黑框相交的替换区域不再被整条丢弃，改为并入黑框（原文真正删除+覆盖），消除「四[黑块]察设计有限公司」类两端原值残留 |
| 旋转扫描页替换文字 | 按页面旋转角绘制替换文字，修正 /Rotate=90/180/270 页替换文字旋转/错位（doc08 假值可读 5/16 → 16/16 审计口径、14/16 强制 OCR 口径） |
| 扫描件 AI 正文文本层 | 扫描页在 AI 模式下补写不可见文本层（OCR 正文 + 假值/占位），纯文本抽取型 AI 可读正文；隐藏层去重（同 text+bbox 的 OCR 重复块只写一次） |
| 替换值叠加重复 | 扫描页可见替换值改为图片渲染（仍可见、可 OCR），可提取文本只保留隐藏文本层一份，消除假值重复出现与页尾成串重复片段 |
| 近似原值假值一致性 | 同一实体的 OCR 变体/简称（跨页/跨字段）统一到同一假值；跨文档内近似分组假值不一致 = 0 |
| 导出文件名中性化 | AI 导出名改为 `AI视图_{内容sha8}_换名_{编号}`，不再沿用源文件名（避免文件名泄漏姓名/公司/金额）；human 命名不变 |
| AI 模式视觉误检降级 | AI 模式下跳过扫描页自动人脸误检（confidence<0.95，且无证件/内嵌图实体），恢复被误检黑块遮挡的标题等内容；human 不变 |
| AI 模式待确认手写签名 | AI 模式下 pending 手写签名按涂黑处理（安全优先）；human 保持人工确认 |

## 三、验收结论

- 回归门禁：`app/tests/regression.py` 硬检查全绿；`app/tests/e2e.py` 5/5；相关域测试与 2 个新增 AI 测试套件通过（详见 `ai_view_test/verify` 与 `ai_view_test/phaseA`、`ai_view_test/batch2` 验收材料）。
- 「给人看」涂黑版：AI 专属修复对其零变化（61 页逐页像素 diff=0）；检测增强带来的新增涂黑均为目标敏感字段（逐项归因见 Batch2 验收报告）。
- AI 换名版：假值可读率、去重、跨字段一致性、映射还原、文件名泄漏等指标均达到验收线；剩余已知项见 Batch2 验收报告。

## 四、已知限制

1. 检测规则仍可能漏检罕见姓/跨行姓名/表格整行合并等形态（宁漏不误）。
2. AI 版扫描件替换文字为图片渲染，文字层位置不保留（仅保证抽取顺序连续）；强制 OCR 精确匹配在个别旋转页可能下降。
3. AI 模式跳过自动人脸误检是基于「证件/内嵌图页保护」的启发式；若文档扫描页含真实人脸照片，AI 版可能不涂黑（human 版仍涂黑）。
4. 跨文档映射仍不共享（同一原值在不同文档可能是不同假值）；组级还原为后续版本能力。
5. 漏检 PII（规则未覆盖的姓名/编号等）在 human/AI 两版均可能残留，产品不承诺匿名化，仅承诺已识别的敏感信息被替换/涂黑。
