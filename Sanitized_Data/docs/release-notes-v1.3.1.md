# v1.3.1 · AI 回件还原（2026-10-29）

> 客户测试版（TestMode）：不启用收费门禁 / 额度限制，界面显示「测试版 · 全功能」。

## 新增

- **AI 回件还原**（exe 界面新标签 `/restore`）：
  大模型拿着「换名版」干完活交回新文件后，在本机按同一 `job_id` 的映射把
  假值换回真值，输出 `*_还原.*` 与还原报告（假值→真值明细 / 告警 / 下载）。
  支持：`docx`、`xlsx`、`pptx`、`pdf`（文本层）、图片（OCR + 重绘）、
  `txt/md/csv/json`。
- **MCP 工具 `restore_sanitize_file`**（16 个工具）：参数
  `path` / `job_id` / 可选 `out_dir` / `include_originals`（默认 false，
  不把真值明细返回给 Agent）。DSH 插件同步显示「回件还原」工具卡。
- 交付弹窗新增「AI 交回文件后 → 回件还原」入口。

## 边界（客户测试时请说明）

- 只能还原「换名」的文本实体；涂黑区域、图片内文字、AI 自己改写/重算/
  编造的内容还原不了，需人工核对。
- PDF 长真值会缩字、版式可能轻微位移；扫描页/图片为 OCR + 近似重绘。
- 金额等比缩放因子反算（AI 自算的合计/税额）为 P1，暂未实现。
- 报告含本机真值，只在本机查看；**不要回传云端模型**。

## 验证

- `test_restore` 18/18、`test_mcp_restore` 12/12、`test_mcp_v2` 37/37。
- `regression.py`：250 项硬检查全绿（红线未破）。
- 真实换名版回件实测：docx/pdf 文本层残留假值 0；图片 OCR 全部还原。
- Playwright + 系统 Edge 界面端到端：上传 → 自动预选映射 → 还原 9 处 →
  明细 8 行 → 下载主成品，console 0 error。
