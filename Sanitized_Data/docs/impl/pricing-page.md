# 04 · 价格页与购买页设计（首页价格区块 / `/pricing` / `/buy` / 控制台升级）

> **状态**：设计规划（未改代码）· 2026-10-20 · 关联 [商业化总览](monetization.md)、[09 定价报告](../research/09-市场定价调研与定价建议.md)、[02 免费版限制](free-tier.md)
> **设计语言**：沿用现有「纸张 / 打字机 / 档案 / 印章」体系（`site.css`、`DESIGN.md §4.2`）；不引入新视觉风格。
> **本批只出设计与文案**，前端实现排期见 [总览 §5](monetization.md)；涉及现有页面的改动都是「加一个链接/一块 section」，不动控制台业务逻辑。

## 0 设计目标与原则

1. **3 秒讲清楚**：用户第一眼知道「免费能用、¥199/年、一天五毛五、随时可买」。
2. **不吓人**：不搞倒计时焦虑、不虚构原价、不把「不买就不能用」写在脸上；免费版真能用。
3. **像这个产品**：纸质档案、朱红印章、黑色涂黑条——价格页是产品气质的延伸，不是电商大促页。
4. **一个价格锚**：主推**个人版 ¥199/年**；其他档位围绕它排列（免费版在左、专业/团队在右、机构版收尾）。
5. **可验证**：所有价格、权益、退款/发票说明与 [09 报告](../research/09-市场定价调研与定价建议.md)、[02 免费版](free-tier.md)、[03 支付](payment-invoice.md) 一致；早鸟限量与结束条件真实可查。
6. **本地页零外链**：产品内页面（`127.0.0.1`）不加载任何外部字体/脚本/图片；购买按钮只是打开系统浏览器。**本地页价格是「参考价」，页面标注「以官网为准」**（零外呼决定了它无法实时更新活动/售罄）。

**不做**：假折扣（划线价注水）、限时秒杀倒计时（除非真实活动）、隐藏价格、默认勾选增值服务、把「免费版」写得像「不能用」。

```

- 放在控制台顶栏（与首页/下载/MCP 导航同一行右侧）；
- 点击「升级/购买」→ 系统浏览器打开公网 `/pricing?from=console`；
- 不在工作区遮挡文件对照。

### 5.2 拦截弹窗（与 02 §6.2 一致）

- 标题 + 一句原因 + 三个动作（升级、导入授权、明天再来/继续用免费版）；
- 弹窗最大宽度 420px，纸面风格，无抖动/闪烁；
- 「升级」按钮颜色用 `--seal`（朱红），其余用 ghost。

### 5.3 `/license` 授权状态页（新页面，产品内）

- 本地静态页 `license.html`，只调 `/api/license/*`（同源）；
- 区块：状态徽章、到期/更新期、本机识别码（复制 + 二维码）、导入授权（拖拽/选择/粘贴）、备份授权、购买/续费、常见问题、审计事件；
- 从控制台顶部状态条/首页页脚进入；
- 设计成「档案卡」：像一张盖了章的授权书；导入成功盖「已核验」章。

1. **免费版有什么限制？**
   每天 3 份、单份最多 20 页、扫描件最多识别 10 页；可用 PDF / Word / Excel / 图片 / 文本和通用规则包。换名、涂黑、对照台、出口自检都能用，不加水印。升级个人版后不限份数和页数，开放全部行业规则包、TIF / 三维和扫描件全页 OCR。

2. **授权是绑定设备的吗？换电脑怎么办？**
   是，一台设备一个授权（专业版 2 台，团队版按席位）。重装系统/重装软件不影响；换电脑联系客服重签，12 个月内首次免费，之后 ¥50/次。

3. **会不会把我的文件上传到你们服务器？**
   不会。产品只监听本机 127.0.0.1，引擎不发起任何外呼，没有账号、没有遥测；所有识别与导出都在你电脑上完成。官网购买只涉及订单信息，不涉及你的文件。

4. **可以开发票吗？**
   可以。支持电子普通发票（个人/单位抬头，3 个工作日内）和增值税专用发票（7 个工作日内）。下单时填开票信息，或支付后在订单页申请。

5. **支持哪些格式？**
   PDF（含扫描件 OCR）、Word `.docx`、Excel `.xlsx`、图片 `.png/.jpg`、纯文本；个人版及以上支持 TIF 正射影像和部分三维格式（OBJ/PLY/GLB/STL）。

6. **买完能退款吗？**
   **还没完成绑定、没生成授权文件**：7 天内可无理由退款；已生成/已激活授权：作为数字化商品不支持无理由退款——购买前请先用免费版或 14 天试用验证。

7. **团队版怎么给成员授权？**
   购买后管理员在后台录入每位成员的「本机识别码」，生成一个团队授权文件，分发给成员各自导入即可；加席位可在后台重签。

8. **机构版包含什么？怎么报价？**
   内网私有化部署、50 席起、定制规则包、审计对接、SLA 与升级服务，¥3.88 万/年起（100 席 5.88 万）。点击「联系顾问」留下单位与场景，我们出方案和报价单。

9. **试用多久？试用后还能用吗？**
   首次启动自动获得 14 天全功能试用（自定义规则包、团队管理台等 P1/团队能力除外）。试用结束后自动变成免费版（每天 3 份、单份 20 页），之前导出的文件不受影响。

10. **以后会涨价吗？老用户会锁价吗？**
    首发早鸟用户**永久按早鸟价续费**。正式价可能随版本升级调整（个人版 199 → 249 等），已付费用户按购买时的价格续费。

```
┌────────────────────────────┐

- 推荐卡：`2px solid var(--seal)`、`background: var(--paper-hi)`、右上角朱红小印章「推荐」（白字、旋转 -6°）；

- 卡片 hover：轻微上浮 + 阴影（已有 `.card:hover` 风格），**不做**闪烁/渐变扫光；
- 买断/早鸟用小字+次按钮，避免抢主价。

### 7.3 对比表样式

- 表头吸顶；个人版列背景 `rgba(178,58,46,.04)` + 顶部 `2px` seal 线；
- 行分组标题（`使用额度` 等）作为整行浅底；
- 移动端：横向滚动，首列 sticky；`overflow-x:auto` 不隐藏滚动条（要能看出可滑）。

### 7.4 页脚与信任元素

- 页脚：`营业执照/ICP 备案（公网站）/价格/退款政策/发票说明/用户协议/隐私政策/客服`；
- 本地页页脚不放营业执照（避免误导），只放功能页链接；
- 机构 banner 用「档案袋」质感 + 「联系顾问」按钮 + 企业微信二维码（P1）。

### 7.5 响应式与可访问性

- 断点：≥1080 四列；720–1080 两列；<720 单列；
- 字号：价格页正文 ≥15px，FAQ 答 ≥14px（目标用户有年长律师/医生）；
- 对比度：`--ink-3` 用于小字时 ≥ 4.5:1 或加粗；
- 焦点可见（`:focus-visible` 2px seal 描边）；
- 尊重 `prefers-reduced-motion`（价格区块无自动动画）；
- 按钮/链接有 `aria-label`；对比表用 `<th scope>`。
