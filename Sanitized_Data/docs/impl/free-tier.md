# 02 · 免费版限制设计（Free Tier / Quota）

> **状态**：设计规划（未改代码）· 2026-10-20 · 关联 [商业化总览](monetization.md)、[01 离线授权](licensing.md)、[04 价格页](pricing-page.md)
> **定位**：免费版是获客入口，不是「残缺试用版」；**安全底线能力（换名/涂黑/本地/出口自检）不阉割**，付费墙放在效率与合规能力上。

## 0 结论先行

| 限制项 | 免费版 | 试用（14 天）/付费 |
|---|---|---|
| 任务数 | **3 份/天**（本地自然日） | 不限 |
| 单文件页数 | **≤20 页**（所有格式；PDF/图片解析前预判，Office 解析后判定） | 不限 |
| 扫描件 OCR | **≤10 页/份** | 不限 |
| 格式 | PDF / DOCX / XLSX / 图片 / 文本 | 全部（含 TIF / 3D） |
| 行业规则包 | **仅通用包**（`common`） | 全部内置包 |
| MCP / 批量 / 审计导出 / 自定义规则包 | ✗ | ✓（按 SKU） |
| 换名 / 涂黑 / 对照台 / 框选补漏 / 出口自检 | ✓ | ✓ |
| 水印 | **无**（不加） | 无 |
| 云端/账号/联网 | **无** | 无 |

免费版必须能完整跑通「一份合同从投放、识别、对照到交付」的闭环——用户是拿真实文件来验证的，不是来看限制清单的。

## 2 限额规则细节

### 2.1 数量与计量口径

| 项 | 口径 | 边界处理 |
|---|---|---|
| 任务数 | 每创建 1 个 Job 计 1 份；同一文件重复处理也算 | 本地自然日 `YYYY-MM-DD` 零点重置；跨天任务按创建日计 |
| 页数 | 以解析后 `Document.pages` 长度为准（`jobs.py` 已有 `len(self.doc.pages)`）；PDF/图片可在解析前用轻量方式预判页数，避免白跑 OCR | 超过 `20` → 拒绝创建，不扣当日额度 |
| OCR 页数 | 需要 OCR 的扫描页数（PDF 扫描页/图片/TIF 多页）；免费版 ≤10 页/份 | 超过 → 拒绝并提示；部分页可 OCR 也不允许拆开绕过 |
| 文件大小 | 沿用现有 `MAX_UPLOAD=512MB`；免费版建议另加 `≤100MB`（防止免费版被当网盘/OCR 机） | 超过 → 拒绝并提示 |
| 规则包 | `GET /api/packs`/`/api/health` 免费版只返回通用包；`create_job` 校验 `pack_ids` 子集 | **无权/非法 pack → 一律 400 `pack_requires_paid`，禁止静默过滤**（否则 `rules.py` 可能把规则丢空而任务照常成功，见 §5） |
| 格式 | `.tif/.tiff`、`.obj/.ply/.glb/.stl` 免费版禁用（直接拒绝） | 在创建 Job 前按扩展名/解析器 format 判定 |

### 2.2 额度消耗与退还

- **消耗时点**：`JobManager.create` 成功返回后（即用户真正开始处理）。
- **退还**：仅当系统错误导致任务在 `detect` 之前失败（如解析器异常、磁盘满）时自动退还 1 份；**页数/OCR 若在解析后才发现超限，也退还该份额度并拒绝**（避免用户白丢额度）；用户主动取消/自己上传错文件**不退**（防刷）。
- **不消耗**：页数超限、OCR 超限、格式不支持、规则包不合法等**前置拒绝**不扣额度。
- **零规则防护（数据泄露级）**：`_run` 进入 detect 前断言编译后的规则非空且条数 ≥ 阈值；为空/过少 → job=`error`「规则包未生效，请检查授权或反馈」，**绝不进入检测/导出**。`rules.py:387` 对未知 pack 会静默丢空、`jobs.py:47-57` 有 fallback，必须在授权层先拒绝非法 pack，不能依赖 `compile_rules`。
- 并发：同一时刻只允许 1 个免费任务（单文件产品本来就是串行体验）；并发发起 → 后一个提示「等当前任务完成」。

### 2.3 时间与时区

- 使用**本地自然日**（与用户直觉一致；`datetime.date.today()`）；
- 内部时间统一 UTC 存储，比较时换算本地日期；
- 时钟回拨：若系统时间早于 `last_seen` 超过 48h，则**不重置日期**、当日额度按已用处理（防止把时钟调到明天刷额度），并显示「系统时间异常」提示（详见 [01 §6.3](licensing.md)）。

## 3 计数与状态（防篡改，尽力而为）

### 3.1 存放

复用 [01 §6.1](licensing.md) 的状态文件（数据根目录 `license/state.json`，含 `usage/date/jobs/ocr_pages/last_seen_utc/flags/sig`；HMAC 签名与冗余策略见 01，本文只约定限额字段，**不要另写一份状态结构**）。

- HMAC 签名（key 由 `build_secret + machine_code` 派生），每次变更重写；
- 冗余：同试用一样另写 `HKCU\Software\BLCTEK\SanitizedData`（Windows）或 `~/.config/sanitized-data/`（macOS/Linux）；读取时**取所有来源中最严格（已用最多、last_seen 最新）**的值，避免删单一文件重置；
- **损坏/删除**：按「已用 1 份」恢复（`state_recovered=true`），并提示「本机状态异常，今日额度已重置为 1 份；如影响使用请联系客服」；**不**升级为「完全不能用」——真实用户可能因崩溃/迁移丢状态。

### 3.2 明确接受的绕过

- 卸载重装/清注册表/换 OS 用户可重置：**接受**（这是离线、低价产品的固有成本；不为此加联网校验）；
- 打包后的程序可被逆向/打补丁：**接受**（见 [01 §9 T5](licensing.md)）；
- 目标不是「防住黑客」，是「让正常用户愿意付费、让绕过成本 > ¥199」。

## 4 拦截顺序与错误码

### 4.1 顺序（先便宜后昂贵，避免白跑）

```
1. 授权状态（paid/trial → 直接放行）
2. 格式白名单（免费版 TIF/3D → 拒）
3. 文件大小（≤100MB 免费）
4. 页数预判（PDF/图片：解析前查页数；Office：解析后查 len(pages)）
5. OCR 页数上限（需要 OCR 时）
6. 当日剩余额度（3 份）
7. 规则包：无权/非法 pack → 400 `pack_requires_paid`（禁止静默过滤）；`api.health`/`api.packs` 只回通用包
8. 进入 JobManager.create → 扣额度；detect 前断言规则非空
```

### 4.2 错误码与文案（API 返回，前端直接用）

| 场景 | `error.code` | 文案（给人看） | 前端动作 |
|---|---|---|---|
| 今日用完 | `quota_exceeded` | 「今天的 3 份免费额度用完了。明天 0 点恢复；也可以现在升级，今天就能继续。」 | 弹窗：升级 / 导入授权 / 明天再来 |
| 页数超限 | `free_page_limit` | 「免费版单份最多 20 页，这份文件有 37 页。升级后不限页数。」 | 弹窗 + 升级 |
| OCR 超限 | `free_ocr_limit` | 「免费版单份最多识别 10 页扫描件。升级后可整份识别。」 | 弹窗 + 升级 |
| 格式不支持 | `free_format` | 「TIF / 三维文件需要个人版及以上。免费版可先用 PDF、Word、Excel、图片。」 | 弹窗 + 升级 |
| 文件过大 | `free_size_limit` | 「免费版单文件限 100MB。更大的文件建议升级后处理。」 | 弹窗 + 升级 |
| 规则包受限 | `pack_requires_paid` | 「该行业规则包需要个人版及以上；请切换通用规则，或升级后使用。」 | 提示 + 升级 |
| MCP 未授权 | `feature_required` | 「MCP 接入需要专业版授权。」 | 提示 |
| 试用结束 | `trial_expired` | 「14 天全功能试用结束了，现在是免费版（每天 3 份、单份 20 页）。」 | 弹窗：升级 / 继续用免费版 |
| 授权无效 | `license_invalid` | 「授权文件无效或已损坏，请重新导入或联系客服。」 | 导入入口 |

文案原则：**说人话、给出路、不羞辱用户**；不写「您已超出免费额度，请充值」这类冷冰冰的句子。

### 4.3 统计与展示

- 控制台顶栏常驻小徽章：`免费版 · 今日剩余 2/3`；
- 上传投放区在选文件后显示「这份 37 页，超出免费版 20 页上限」的预检结果；
- 授权状态页显示当前版本、到期、额度、机器码、升级入口（见 [01 §6.6](licensing.md)）。

## 5 执行点（后端为准，UI 只是提示）

| 位置 | 改动 | 说明 |
|---|---|---|
| `api.create_job` | 调 `quota.check_and_consume(path, fmt, packs, strictness)`；非法 pack → 400 | 前置拒绝不扣额度；成功扣 1 份 |
| `jobs.JobManager.create` | 调 `quota.check_defense(...)` | 防绕过 HTTP 直接调（MCP 也走这里） |
| `jobs._run` / 解析完成后 | 页数/OCR 页校验（Office）；**detect 前断言规则非空/条数达标** | 超限 → 任务置 `error`，退额度；空规则 → `error`「规则包未生效」，绝不导出 |
| `api.packs` / `api.health` | 按授权过滤 | 免费只回通用包；health 的 packs 字段同步过滤 |
| `mcp_server.py` 工具入口 | `licensing.require_paid("mcp")` + `quota.check_defense` | 免费版直接返回错误，不执行 |
| **`POST /api/jobs/{jid}/export` / `/file`** | **永不 gate**（换名/涂黑成品导出） | 免费/试用到期都必须能导出成品；限额只在创建任务时 |
| `GET /api/audit/export`（**P1 新增**） | `audit_export` 功能位 | 导出审计/复检报告需付费；当前仓库无此接口 |
| `GET /api/audit`、`POST /api/audit/verify` | 免费可看/可验 | 不 gate |
| `web/app.js` | 状态条/额度/弹窗/授权页 | 展示层 |
| `web/index.html` | 授权状态入口 + 升级 CTA | 控制台入口 |

> **不要**在解析器/检测器/替换器内部加限额判断（污染管线、难测试）；全部收在 `quota` + `licensing` 两个模块。

## 6 免费版 UX（与控制台现有风格一致）

### 6.1 常驻状态条（控制台顶部）

> 文案以 [04 §6.1](pricing-page.md) 文案库为准，本节只给状态类型；实现时不要两处各写一套。

```
┌──────────────────────────────────────────────────────────────┐
│ 免费版 · 今日剩余 2/3 份  · 单份 ≤20 页   [升级个人版 ¥199/年] │
└──────────────────────────────────────────────────────────────┘
```
- 试用期显示：`全功能试用 · 剩 9 天  [购买授权]`；
- 付费显示：`个人版 · 2027-10-20 到期  [续费]` / `专业版` / `团队版`；
- 免费版不弹全屏广告；每天最多提示一次升级。

### 6.2 拦截弹窗（示例文案）

```
今天 3 份免费额度用完了
明天 0 点自动恢复。也可以现在升级，今天就能继续处理。

[升级个人版 ¥199/年（早鸟 ¥99）]  [导入授权文件]  [明天再来]
```
- 「导入授权文件」→ 授权页（支持选择文件/粘贴文本）；
- 「升级」→ 打开系统浏览器到官网价格页（本机页面不带外链脚本，只跳转）。

### 6.3 试用引导

首次启动（免费用户）：
```
┌─────────────────────────────────────────────┐
│ 先免费用 14 天全功能                          │
│ 不限份数、不限页数，所有规则包都能用。         │
│ [开始试用]   [先看看免费版]                    │
└─────────────────────────────────────────────┘
```
- 默认推荐开始试用，但保留「先看看免费版」入口（有些用户不喜欢「试用后收费」的压迫感）；**选择先看看 → 试用资格保留，在 `/license` 随时启用（仅一次，启用后 14 天）**；不因延迟而增加总时长；
- 试用结束前 3 天提示一次。

### 6.4 不做的「坏设计」

- ❌ 免费版输出加可见水印（律师交出去的文件带水印=不可用，直接流失）；
- ❌ 免费版降低识别精度/严格度（损害信任）；
- ❌ 免费版隐藏「出口自检」（安全底线不能成为付费点）；
- ❌ 每日弹窗轰炸/倒计时焦虑；
- ❌ 把「免费版」叫「体验版」然后限制到无法完成任务。

## 7 迁移与测试环境

### 7.1 对现有测试的影响

- 现有 e2e/回归（5 样例、46 实体、红线门禁）默认全功能 → 实施时：
  - 测试启动前把测试授权文件写入临时 `YINZHAN_DATA_DIR/license/license.json`（测试密钥对，仅源码模式信任）；
  - 或 `YINZHAN_DEV_EDITION`（仅 `not FROZEN` 生效）——**二选一，建议前者**（少一个生产后门）。
- 回归样例不因免费限额改变输出（除明确测免费限额的用例）。

### 7.2 迁移

- v1.0.0 升级用户：首次启动得到**试用资格**（默认引导启用，14 天全功能），之后免费版；老用户赠送政策见 [01 §12 L4](licensing.md)；
- 数据兼容：新增数据根目录下 `license/` 目录；不迁移/不删除既有数据；
- 回滚：降级到旧版本 = 无授权概念，全功能（可接受，旧版本不商用分发）。
