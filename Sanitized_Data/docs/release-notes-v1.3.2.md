# v1.3.2 · 回件还原 E2E 修复版（2026-10-29）

> 客户测试版（TestMode）：不启用收费门禁，界面显示「测试版 · 全功能」。
> 本版基于真实端到端测试（测试集脱敏 → 子代理盲读产出回件 → 回件还原 → 与原文对照）
> 修复了 3 个会导致「真值没换回来」的问题，并补强风险提示。

## 修复（回件还原）

1. **带标签的核心号码**：AI 回件常把 `账号:6679…`、`住院号：WR…` 只抄成号码本身。
   现在会生成「去标签核心写法」匹配项，既能把账号/住院号换回真值，也不会再出现
   `住院号 住院号：ZY…` 这种前缀重复。
2. **结构化值写法差异**：案号等值在回件里可能少空格 / 用中文括号
   （`[2024 ]…` → `[2024]…`）；现支持空白压缩、中文/全角括号归一，案号可正确还原。
3. **Excel 纯数字单元格**：AI 把金额写成数字单元格（无 ¥/元）时，现在按金额映射
   还原（支持元/万元），公式单元格不破坏。

## 增强

- 报告新增提示：
  - 「AI 自行计算/推断的数字与结论不会自动还原，需人工复核」；
  - 「映射库含疑似 OCR/版面误检实体（如人名=公章、机构=按照银行），还原可能语义异常」；
  - 「PDF 为文本层重绘，字体/字距/缩字与版式可能轻微变化」。
- 单测从 18 项增至 22 项（派生核心写法、空白/括号变体、xlsx 数值金额、低质量映射告警）。

## 仍属已知边界（测试时请向客户说明）

- 涂黑区域、图片内文字、AI 改写/重算/编造的内容不可还原；
- AI 基于假值的推算/结论（身份证推生日、自算合计、引用局部区号等）还原后可能
  自相矛盾，必须人工复核；
- 映射库若含 OCR 误检实体，还原会忠实换回错误原值，报告会告警，需上游过滤；
- PDF 长真值会缩字、版式可能轻微位移。
