## 产品定位（法务先看这一段）

- 数据隐站是**本机运行的辅助工具**，帮助用户对文件中的敏感信息做识别、换名/涂黑、导出和回件还原；
- 文件默认只在用户本机处理，产品引擎不把文件内容上传到服务器；
- 产品**不提供法律意见**，不承诺“去标识化=匿名化”，不承诺处理结果满足任何特定法律法规、行业规范或监管要求；
- 用户必须自行确认其处理行为合法、已取得必要授权，并对处理结果进行人工复核；
- 购买/支付只涉及订单信息（订单号、商品、金额、机器码、可选邮箱）和支付宝交易信息，不涉及文件内容。
