## 0 结论先行

### 0.1 MCP 服务怎么收费（直接答案）

| 项 | 建议 |
|---|---|
| **MCP 单独定价？** | **不单独出 MCP SKU**。MCP 是**专业版功能位**：专业版 ¥499/年（早鸟 ¥299/限 300，续费恢复 ¥499；买断 ¥999，不含跨大版本更新）。 |
| **免费版给 MCP 吗？** | **建议**只给只读小工具：`list_rules`、`check_support`、小文本 `redact_text`（建议 20 次/天）——**D-M1 待拍板；未拍板前按 plan 05 的「MCP 全 Pro」执行**。文件写操作 / L2 Job 复核 / 导出 / 还原 / 审计一律需专业版；14 天试用全功能。 |
| **团队/机构** | 团队版 **¥1,999/年/5 席**（≈400 元/席·年）；现有在售 3 席 ¥1,299、10 席 ¥3,499；**建议** 10 席改 **¥3,999**、新增 20 席 **¥6,999**（D-M2 待拍板）。机构版 **¥3.88 万起**，可加购 **MCP 接入包 ¥1.5–3 万/项目**（同机 MCP 部署/规则/审计模板；不含集中网关）。 |
| **怎么收** | 年付/买断订阅 + 席位/项目合同：软件内购（A 静态码 / B Native 扫码）+ 官网购买 + 团队/机构对公合同；Agent 返回 `license_required` 引导用户购买，**绝不让模型代付**。 |
| **按调用收费？** | **不做**。全球单次调用约 **¥0.0007–0.67**（$0.0001–$0.10：Smithery RPC 下限、x402 $0.001、Exa 搜索约 $0.004–0.012）、国内 MCP 平台 0.01–0.03 元/次；扣通道费后无意义，且与本地零外呼/无账号冲突。 |
| **一句话定位** | 卖的不是「能接 MCP」，是**「文件先在本机脱敏，再交给 Agent」**；MCP 只是让 Agent 自动调用这个能力。 |

### 0.2 要不要自己的客户管理系统记录 license？

**要一个「授权与客户台账」，不要一套完整 CRM。**

- license 记录必须**自有、自建**：`licenses` 表 + 订单/支付外键是唯一事实源。Keygen/Cryptlex/LicenseSpring 等只能做 P2 的「查看/自服务门户」，**不能做主库**（数据出境、无中国发票、停服风险、订单与授权被切成两段）。
- P0 客户台账：自建商业服务 DB（客户/订单/授权/发票/退款）+ **企业微信（客服）+ 飞书多维表格（销售台账，免费）**；CRM 采购预算 **¥0**。
- P1 再评估低代码 CRM（明道云 ¥14,900/年 或 简道云 ¥8,000 起/年）；专业 CRM（纷享销客/销售易）P2、按销售团队规模再说。
- 离线 Ed25519 授权自建约 5–7 人日，0 订阅费；比 Keygen Std1（$99/月≈¥665/月、¥6,653/年）更便宜且边界干净。

### 0.3 收费管理系统的前后端要补什么（一句话）

现有 [payment-invoice.md](../impl/payment-invoice.md) 是**设计稿（未实现）**，覆盖「订单/支付/回调/绑定/签发/发票/后台」骨架；要补的是**客户与组织档案、客户自助门户、团队/席位、续费自动化、优惠/渠道、报表、工单、权限审计、对账导出、MCP/Agent 治理**。完整设计见 [billing-system.md](../impl/billing-system.md)；P0 **固定 SaaS 采购≈0**（交易/服务器/发票为变动成本），P0a–P2 合计约 **90–130 人日**（2 后端 + 1 前端约 3–4 个月）。

## 2 我们的 MCP 现状与商业边界

### 2.1 产品能力面（v1.2.x）

- **15 个工具**：4 个基础（`sanitize_document`/`redact_text`/`check_support`/`list_rules`）+ 11 个 L2（`sanitize_file`、`get_sanitize_job`、`list_sanitize_jobs`、`get_sanitize_entities`、`update_sanitize_entity`、`mark_sanitize_region`、`accept_all_sanitize_entities`、`export_sanitize_job`、`get_sanitize_audit`、`rehydrate_sanitize_text`、`open_sanitize_workbench`）；
- **4 个资源模板 + 1 个 jobs 列表资源**：`sanitize://jobs`、`sanitize://jobs/{id}`、`.../entities`、`.../audit`、`.../pages/{n}`；**2 个 prompts**：复核、工作台回退；
- **交付**：`Sanitized_Data_MCP.exe`（随安装包）、源码 stdio、DSH 插件/工具卡；实测 WorkBuddy 5.8.4、Codex、Claude Desktop/Code、Cursor、DSH 等；
- **安全**：本机 stdio/127.0.0.1、引擎零外呼；human 导出有 confirm_token；审计只记类型/数量/哈希。

### 2.2 已有商业口径（[plans/05](../plans/05-付费与解锁-软件内购与ICP过渡-规划.md)）

- 首发 v1.2.0 起带 licensing + 14 天试用 + 存量用户 1 年专业版保护；**MCP/DSH 检测纳入专业版**，试用后付费；v2.0 起全面按专业版收费；
- 专业版年付 ¥499（早鸟 ¥299 限 300、买断 ¥999）；个人版 ¥199（早鸟 ¥99、买断 ¥499）；团队 ¥1,999/5 席；机构 ¥3.88 万起；
- 购买通道 A（静态码/授权码，零外呼）/ B（Native 扫码自动解锁，用户点击时联网）双模式，服务端切换。

> **版本与迁移（建议 D-M9）**：licensing 首次上线目标版本 **v1.3.0**（兼容 v1.2.x 数据）；v1.2.x 存量用户按 plan05 P3 赠 **1 年专业版**，用 `grant_license` 批量签发（plan02 写 Personal，需统一为 Pro）；v1.2.x 已发版说明「MCP 原免费」，需提前公告。
> **页面口径**：当前 `mcp.html`/`home.html` 只讲“能接 Agent”，没有授权/免费范围/升级入口；v1.3.0 需加「免费只读 / 专业版文件能力 / 授权状态 / 升级」一节，否则用户按页面配置后直接撞 `license_required`。

> **本报告的建议与上述口径一致**：MCP 绑专业版、不单独 SKU、不做按次；只新增「免费只读 MCP 工具」与「团队/机构 MCP 治理包」两个边界，作为增长与溢价点（见 §5.5、§5.7）。

## 3 全球 MCP 定价市场（A 线）

### 3.1 MCP 相关产品怎么收费：五种形态

| 形态 | 做法 | 实测案例 | 价格带 |
|---|---|---|---|
| **免费开源/免费引流** | MCP server 开源，靠 API 或上层产品变现 | Exa 免费档含 MCP；Pipedream Free 含 MCP servers；GitHub Copilot Free 也能接 MCP；PayMCP 开源 MIT | $0 |
| **订阅/席位** | 按人/月/年，MCP 是 feature 之一 | Cursor、Copilot、Claude、Windsurf、Tailscale | $8–200/席/月 |
| **按调用/credit** | 按 API 调用、credit、RPC、浏览器小时计费 | Firecrawl、Exa、Tavily、Browserbase、Smithery RPC、x402 ($0.001/次) | 单次 <$0.1；月订阅 $10–99 |
| **平台捆绑** | MCP 不单独卖，含在既有产品档位 | Codex 含在 ChatGPT 计划；GitHub Copilot 全档含 MCP；Anthropic web search 按能力计费 | 无独立价 |
| **企业定制/网关治理** | 卖认证、审计、配额、SLA | Kong AI Management、Zuplo Enterprise、Pipedream Business、1Password | $25/月起，企业 $1,000+/月起 |

### 3.2 三个关键价格锚

1. **个人 AI 工具中位价 $20/月（≈¥134/月、¥1,600/年）**：Cursor Plus $8、Copilot Pro $10、Claude Pro $17–20、Windsurf Pro $20、Cursor Premium $30 → **¥54–202/月**。
   → 数据隐站 ¥499/年 ≈ **$6.2/月**，约为国际个人 AI 工具中位的 **1/3**；但本地工具无模型算力成本，**不能按 AI 订阅对标**。
2. **重度档 $100–200/月（¥672–1,344），2026 出现 $500/月（¥3,360）**（ChatGPT Pro 三档）；这些含模型算力，本地工具不可比。
3. **按调用约 $0.0001–0.10/次（¥0.0007–0.67）；MCP 网关 $25–$1,000+/月**：Smithery RPC $0.10/1K（$0.0001/次）、x402 $0.001/次、Exa 搜索 $4–12/1K、Zuplo Builder $25/月、Kong $25/月起 + 计量 $20/百万事件 + 0.4% 计费流水。（raw-A 中「$0.001/次下限」与 Smithery 口径差 10 倍，本报告取全区间；结论不变）
   → **单次调用撑不起 SKU**；本地离线产品更无法做调用计量与收款。

### 3.3 生态异常与免费额度惯例

- **中间层在洗牌**：Smithery 公告 MCP Proxy 与 managed identity **2026-10-31 关停**；Cursor 页面已是 xAI/Grok 捆绑形态；Windsurf 页面已是 Devin（Cognition）品牌。→ **不要把 MCP 市场/托管当护城河**。
- **免费额度是标配**：Firecrawl 1,000 credits、Tavily 1,000 credits、Smithery 50K RPC、Zuplo 100K 请求、Tailscale 6 用户、GitHub Copilot Free 也能接 MCP；共同点是**能跑通完整链路，但额度/高级能力受限**。

## 4 国内 MCP/Agent 价格与付费锚（B 线）

### 4.1 国内 AI 工具价格带（2026-10）

| 带 | 价格 | 代表 |
|---|---|---|
| 入门 | **¥19.9–59/月** | 无问芯穹 19.9、百炼/方舟 40、Kimi/TRAE Lite/GLM Lite 49、Qoder Pro 59 |
| 主流 | **¥99–199/月** | CodeBuddy 99/199、TRAE Pro 99、Kimi Moderato 99、GLM Pro 149、Qoder Pro+ 169 |
| 高端 | **¥469–999/月** | GLM Max 469、豆包专业版 500、TRAE Ultra 699、CodeBuddy 旗舰 999 |
| 企业席位 | **¥99–316/席·月（≈¥1,188–3,792/席·年）** | Qoder Teams 99/企业 149/VPC 199；CodeBuddy SaaS 198/专有云 316（100 席起） |

### 4.2 国内 MCP 平台：广场免费，计费在调用侧

- 阿里云百炼、腾讯云 MCP 广场（Hosted 免费云资源）、百度千帆（免费托管）、魔搭 MCP 广场（免费云端资源）——**MCP 触达/托管免费是生态默认**；
- 收费发生在调用：百炼 Managed Agents **0.5 元/小时**会话运行时、内置 `web_search` **0.03 元/次**；支付宝 MCP **0.01 元/次**；
- 腾讯云 MCP 广场目前**不开放第三方 MCP 上架**——生态尚未形成"卖 MCP"的市场。

### 4.3 企业数据安全/脱敏价格锚（机构版参照）

| 项目 | 价格 |
|---|---|
| 数据库静态脱敏软件（金融） | **18.8–21.7 万元/套**（中信金融资产三家竞标） |
| 数据脱敏加密软件 | **42.9 万元/套**（中国物品编码中心，项目总 84.66 万） |
| 数据安全加固项目 | **54.5 万元**（北部湾保险，含实施/规范） |
| 数据脱敏开发服务人月 | **2.67–4.55 万元/人月**（光大银行） |

→ 机构版 ¥3.88 万 ≈ 1/5–1/10 套软件、≈1 个人月高级工程师；**价格安全，但必须清单化交付**（私有化、审计、规则包定制、PIPL 话术、发票合同），否则会被当"个人版企业授权"压价。

### 4.4 目标人群付费能力

- 律师：**96% 个人在用生成式 AI**，但律所层面常规化仅 **28%**，47% 计划两年内推行 AI 战略；
- 医生：中国临床医护使用率 **71%**（全球 48%）；
- 财会：**92%** 企业已用 AI、74% 持续用网络安全软件；
- 职场人：**56.1% 愿为 AI 付费，仅 23.4% 实际付费**；愿付理由首两位是"更精准/更高质量"（80.8%）与"更专业的领域知识"（65.7%）；
- 同类专业软件年费：福昕商业版 **480 元/人/年**；用友好会计 **498/898/1,998/2,998 元/年**。

### 4.5 对定价的含义

1. **¥499 专业版是最合适的主力档**：夹在福昕 480、用友 498 与 Kimi 年付 468、GLM Lite 588 之间，用户不会觉得"本地小工具凭什么 499"；
2. **MCP 不能单独卖**：国内四家 MCP 广场都免费，无市场参照；按次价 0.01–0.03 元/次折算一年 1,000 次才 10–30 元，远低于 ¥499；
3. **团队版 400 元/席·年明显低于企业席位价**（¥1,188–3,792/席·年），保留 5 席 1,999 作为最小包，新增 10 席档承接小律所/诊所/代账；
4. **机构版 3.88 万安全但不冒进**，需清单化；
5. **不要主卖"能接 WorkBuddy/Codex"**：元宝 Agent 全免费、豆包 68 元/月——"能接 Agent"已是免费能力；主卖点是**本地脱敏 + 可复核/可还原/可审计**。

## 5 MCP 定价结论

### 5.1 三种模式对比

| 模式 | 市场证据 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| **独立 MCP SKU**（按年/月） | Copilot 全档含 MCP、Codex 不单卖、Exa/Tavily 把 MCP 当入口；国内 MCP 广场免费 | 定价清晰 | 用户困惑"接协议还要钱"；与免费核心能力打架；无市场参照 | **不做** |
| **按调用/按次** | 单次约 ¥0.0007–0.67（$0.0001–$0.10）；PayMCP 明示不兼容本地 stdio；x402 主流客户端不支持；国内 0.01–0.03 元/次 | 用多少付多少 | 收不到钱（覆盖不了通道费）；与零外呼/无账号冲突；本地无云成本依据 | **不做** |
| **订阅/席位捆绑（推荐）** | 全球 AI 工具/企业软件主流；Tailscale $8–18/席/月；Claude Team $20–100/席/月 | 可预测、与离线授权天然匹配、用户易懂 | 需要 license/支付系统 | **做** |

### 5.3 为什么是这些数字（锚点推导）

- **Pro ¥499/年**：≈$6.2/月，是国际 AI 工具中位（$20/月）的 1/3；国内落在福昕 480、用友 498 与 Kimi 468、GLM 588 之间；**不按 AI 订阅定价，按专业软件定价**；
- **早鸟 ¥299**：≈6 折，限 300 份、仅首年、续费恢复 499——避免长期锚死在 299（国内 Coding Plan 的低价钩子通常正价承担锚点）；
- **团队 400/席·年**：只有企业 AI 席位价（¥1,188–3,792/席·年）的 1/3–1/10，保留 5 席最小包；**建议** 10 席档由现价 ¥3,499 调至 ¥3,999（400/席）、新增 20 席 ¥6,999（350/席），需 D-M2 拍板；
- **机构 3.88 万**：1/5–1/10 套企业脱敏软件；MCP 接入包 1.5–3 万 ≈ 0.5–1 个人月高级工程师，符合轻量项目采购；
- **不按调用**：全球单次约 ¥0.0007–0.67、国内 0.01–0.03 元/次，扣通道费后负；本地无云成本。

### 5.4 怎么收（渠道、授权、票据、续费）

| 环节 | 做法 |
|---|---|
| 购买入口 | 软件内购弹窗（A 静态码/B Native 码）、官网 `/pricing`→`/buy`、DSH 工具卡升级按钮、团队/机构合同 |
| 支付 | 微信/支付宝直连（0.6% 级）P1；P0 对公转账 + 人工签发；个人早鸟可平台卡密（合规前提下） |
| 授权 | 付款后绑定机器码 → 下载 `license.json` → 本地导入；MCP server 与 GUI 共用同一授权；**Agent 不代付**，工具返回 `license_required` + purchase_url |
| 续费 | 到期 30/14/7/1 天提醒；宽限 14 天；续费新 license（同机器码、新到期）；**正式价用户锁正式价，早鸟首年后续费恢复正式价（早鸟用户可 9 折，D-M8 待拍板）** |
| 发票 | 普票半自动（P0 人工）/云开票（P1）、专票人工；退款红冲 |
| 团队/机构 | 团队 license 含 N 个机器码；机构绑服务器 + 合同 + MCP 接入包（与 base 交付互斥，见 §5.7） |

### 5.5 免费 MCP 只读策略（与 plan 05 的差异，需拍板）

- **plan 05 现状**：MCP 整体属专业版，免费无 MCP；
- **建议细化**：免费给只读小工具（`list_rules`/`check_support`/`redact_text` 20 次/天），文件写/L2/导出/还原/审计仍需 Pro；
- **理由**：国际 Copilot Free 也能接 MCP、免费档"能跑通但高级能力受限"是行业惯例；只读工具不产生成品、不替代 GUI 免费版，却能让 Agent 用户先"发现工具"，再为文件写操作升级；
- **风险**：免费用户可能只用只读工具、不升级——可接受（获客成本低）；若转化数据差，可收回为 plan 05 的"全 Pro"。
- **决策点**：D-M1（见 §8）。

### 5.6 不做清单

- 不做 MCP 单独 SKU；不做按调用/按次；不做 MCP 市场/托管/代理（中间层在洗牌）；
- 不做云端 MCP 网关（与本地定位冲突）；若未来做独立云产品，另定价；
- 不把「能接 WorkBuddy/Codex/DSH」当主卖点；
- 不虚构原价/倒计时；早鸟写清"限量+首年+续费恢复"。

### 5.7 团队/机构 MCP 治理（第二增长点，但别承诺联网控制）

- 团队：Pro 全部 + **本地审计导出**（`origin=mcp` 的任务/类型/哈希；管理员逐机导出、人工汇总）+ 共享规则包（管理员分发文件、本地导入）+ 管理台（P1 席位/机器码/到期/续费）；5 席 1,999 起；
- 机构：**MCP 接入包 ¥1.5–3 万/项目**：同机 MCP server 部署、Agent 客户端接入配置、MCP 审计字段/SIEM 对接模板、规则包、培训；**不含集中式 MCP 网关**（多用户/鉴权/隔离/网络改造需另立项，当前 `mcp_server.py` 只支持同机 127.0.0.1 + 本机 Web，无账号/Job owner）；
- **3.88 万 base 与 MCP 接入包互斥清单**：base 含通用内网部署/审计/SLA，MCP 包只补 MCP 专项，不重复收部署费；
- Agent 白名单只能基于本地配置/客户端自报 `clientInfo`，属**提示性**，不作强制控制卖点；不做云端规则下发/审计回收；
- 不按"每人一个 MCP license"卖机构；按服务器授权 + 合同席位。

> **结果付费补充**：GUI 侧“预览满意后按次付费导出”方案见 [14 报告](14-结果付费方案设计与对比.md) 与 [result-payment](../impl/result-payment.md)；MCP 不参与按次付费（无 Pro/credits 时返回 `payment_required`），团队/机构不开放。

## 6 要不要自己的客户管理系统记录 license？

### 6.1 结论

**需要「授权与客户台账」，不需要「完整 CRM」。**

| 能力 | 要不要 | 放在哪 |
|---|---|---|
| license 记录（license_id、机器码、到期、功能位、状态） | **必须自有** | 自建 `licenses` 表 + 订单/支付外键 = 唯一事实源 |
| 客户档案（手机/邮箱/单位/联系人） | **必须自有** | 自建 `customer/org/seat` 表（最小字段） |
| 订单/支付/发票/退款 | 必须自有 | 自建购买服务（见 [payment-invoice](../impl/payment-invoice.md)） |
| 销售线索/商机/漏斗 | 不需要自建 | P0 飞书多维表格/企微；P1 低代码 CRM；P2 专业 CRM |
| 客服工单 | P1 | 自建简单工单表；量大再买美洽等 |
| 营销自动化/呼叫中心 | 不需要 | 不做 |

### 6.2 license 记录放哪：自建 vs 第三方 license SaaS

| 方案 | 价格 | 能力/限制 | 结论 |
|---|---|---|---|
| **自建 Ed25519 离线授权**（本仓库设计） | 0 订阅费；5–7 人日 | 离线验签/机器码/试用/宽限/功能位；中国主体/人民币/发票/数据完全兼容 | **P0 推荐** |
| Keygen Cloud | Dev $0（100 ALU）；Std1 **$99/月≈¥665/月、¥6,653/年**（1,000 ALU） | 离线 license+设备激活+管理台；美元结算、数据境外、无中国发票 | P2 备选（仅门户） |
| Keygen CE/EE 自托管 | CE 免费；EE 未公开（推断 4 位数美元/年） | 可自托管；仍需美元购买/运维；无中国发票 | P2 备选 |
| Cryptlex | Starter **$100/月≈¥672/月**；Growth $300/月 | 离线激活/浮动/审计；境外/无中国发票 | P2 备选 |
| LicenseSpring | Free $0（含离线）；Starter **$199/月≈¥1,337/月** | 离线/节点/计量；境外/无中国发票 | P2 备选 |
| Licentric | Free（100 license）；**$5 / $29 / $199 月**（≈¥34/195/1,337） | 支持 Ed25519 离线文件 + Stripe 计费；SOC2 未取证、非官方对比页数据 | P2 备选（仍不推荐做主库） |
| LimeLM | Free；Basic **$47/月≈¥316/月**（1,200 激活） | 桌面软件老牌、离线激活；境外/英文 | 不建议做主选 |
| LicenseGate（开源） | $0 许可费；自托管 | 基础 key 校验；**无 Ed25519 离线文件**，需自己加 | 不建议 |

**为什么 license 必须自建做主库**

1. **离线授权**：产品零外呼，license 必须能在无网络时验证；第三方 SaaS 的"云激活"不适用，离线文件仍要自己签；
2. **中国商业链路**：订单→支付→绑定→签发→发票→退款是一条链；第三方只覆盖"签发/管理台"，订单/发票/对账仍自建，边界被切两段；
3. **数据合规**：手机号/邮箱/发票信息是个人信息；P0 全部落境内，不引入上传客户数据的境外 SaaS；
4. **成本**：自建 5–7 人日 vs Keygen ¥6,653/年（且仍需自建其余），自建更便宜；
5. **停服/涨价风险**：Keygen/Cryptlex/LicenseSpring 均为境外小厂/独立产品，长期存在不确定性（本次已见 Smithery 关停、Cursor/Windsurf 被并购）。

### 6.3 客户台账 vs CRM：分阶段

| 阶段 | 客户台账 | 预算 |
|---|---|---|
| **P0**（现在） | 自建 `customer/org/order/license/invoice` 表；客服用企业微信；销售台账用飞书多维表格（免费） | **¥0** |
| **P1**（团队/机构起量） | 低代码 CRM-lite：明道云 Standard **¥14,900/年**（30 用户）或简道云标准版 **¥8,000 起/年**；先试用 | ¥0–1.5 万/年 |
| **P2**（销售组织） | 纷享销客/销售易（未公开报价，销售报价/实施）；仅当销售 ≥2 人、线索 >100/月 | 需询价 |
| 电子合同 | e签宝/法大大（未公开价，按份/套餐）；仅团队/机构合同 | 按需 |
| 客服 | 企业微信/邮箱 P0；美洽等 P2 | ¥0 |

## 7 收费管理系统全景：前后端需要什么

> 详细设计见 [billing-system.md](../impl/billing-system.md)；这里给决策层清单与缺口。

### 7.1 总体架构（一句话）

### 7.4 数据模型

核心表：`customer / org / seat / orders / order_items / payments / refunds / licenses / license_bindings / subscriptions / invoices / grants / coupons / campaigns / channels / tickets / notifications / audit_logs / admin_users / roles`（**表名以 payment-invoice 为准**，billing-system 已统一）。字段与索引见 [billing-system.md §4](../impl/billing-system.md)；`licenses.order_id` 可空以支持存量 grant。

### 7.5 建设顺序与估算

| 阶段 | 内容 | 人日（P0 起） | 现金支出 |
|---|---|---|---|
| **P0a 收款前闭环** | 授权内核 + 免费版 + 内购入口 A + 客户台账最小集 + 对公/人工签发 + 发票人工 + 后台基础 + 存量 grant | **28–36** | 固定 SaaS≈0；服务器/短信/发票按变动成本 |
| **P0b 线上收款** | 微信/支付宝直连、回调/对账、绑定自动签发、Native B、云开票、退款自动化 | **+20–28** | 支付费率 0.6% 级；云开票按张 |
| **P1 运营完善** | 客户门户、团队/席位、优惠/渠道、续费自动化、报表、工单、发票自动化、RBAC、MCP 治理（本地） | **+25–35** | CRM-lite ¥0–1.5 万/年 |
| **P2 规模化** | 机构合同/报价、CRM/财务集成、电子合同、海外 MoR、集中 MCP 网关（另立项） | **+20–30** | 按需 |
| **合计** | 完整收费管理系统 | **约 90–130** | 2 后端 + 1 前端约 3–4 个月（并行） |

> **取舍**：若赶 11 月早鸟，只做 P0a（28–36）+ 人工/对公；P0b/P1 后置。若砍掉 P1/P2 的 CRM/电子合同/海外 MoR/集中网关，可压到约 **75–95 人日**。原「60–90」为低估，已按模块重估。

> **人力提示**：P0 的 W1/W2/W4 都压在后端，1 名后端做不完；按上表排期需 2 名后端（或 W4 外包支付服务商）。

### 7.6 建设顺序建议

1. **W1 授权内核 + free-tier 限额**（不依赖资质，可先做）；
2. **W3 价格页/内购入口/`/license`**（可先做）；
3. **W4 购买服务**（订单/回调/绑定/签发/发票/后台；商户号到位后真实联调）；
4. **客户台账/团队/续费/报表**（P0a 后半 → P1）；
5. **MCP 治理/机构接入包**（P1/P2，随团队/机构起量）。

> **P0a/P0b 分界**：P0a 只做“不依赖商户号也能收到钱”的部分（对公/卡密/人工签发/授权/台账）；P0b 等 ICP+商户号后做 Native 支付/自动解锁/自动开票/自动对账。不要把 P0b 压进早鸟排期。
