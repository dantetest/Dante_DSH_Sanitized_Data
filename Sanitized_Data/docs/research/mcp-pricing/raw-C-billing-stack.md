## 0 结论先行（直接回答）

1. **「客户管理系统」需要，但不是「买一套 CRM」**：0–50 人、单产品线、客单价 ¥99–¥4 万的软件公司，真正需要的是**客户/订单/授权/发票/续费台账**。它天然长在自建购买服务的 DB 里（`buyers / orders / payments / licenses / invoices / refunds / tickets`），P0 用**自建后台 + 企业微信 + 飞书多维表格（免费）**即可；**不建议 P0 采购纷享销客/销售易**（未公开报价、销售流程管理价值低、数据合规多一层）。
2. **license 记录放自建核心，不要放第三方 license SaaS**：`licenses` 表 + 订单/支付流水外键是唯一事实源；第三方（Keygen/Cryptlex/LicenseSpring/LimeLM）只适合 P2 做「自服务门户/多产品线管理」的备选，**不能做主库**——数据出境（PIPL）、无中国增值税发票、停服/涨价风险、以及「订单-授权」边界会被切成两段。
3. **离线 Ed25519 授权文件自建是正确且便宜的**：设计已完成，W1 约 **5–7 人日**（推断 ¥0.4–1.05 万，按 ¥800–1,500/人日）；而 Keygen 起步档 $99/月（≈¥665/月、¥6,653/年）只买「云端许可 API + 管理台」，**离线签发、订单绑定、发票、退款仍要自己写**，且数据在境外。
4. **支付主通道只能是境内直连**：微信支付/支付宝常见 **0.6% 级**费率；全球 MoR（Paddle 5%+$0.50、Lemon Squeezy 5%+50¢、Gumroad 10%+$0.50）**贵 8–18 倍**，且开的是境外发票、中国内地主体能否入驻需另行确认 → 定位为 P2「海外/外币收款」备选，不是主通道。
5. **P0 推荐组合**：自建商业服务（订单/回调/绑定/签发/发票队列/后台/对账）+ **对公转账 + 人工签发**过渡 + 企业微信客服 + 飞书多维表格客户台账 + **第三方云开票（P1，普票自动/专票人工）**；CRM 采购预算 **¥0**，license SaaS 预算 **¥0**。
6. **要补的前后端**（与既有设计一致）：后端 = 订单/支付回调（验签+金额核对+幂等）/绑定与签发/发票队列/退款/对账/后台 2FA；前端 = 价格页/购买页/绑定页/订单查询/授权状态页/发票申请页/后台。W4 约 **15–20 人日**（推断 ¥1.2–3.0 万），CRM 与客服不占开发量。

## 7 对收费管理系统选型的建议（12 条）

1. **【P0｜买 vs 自建】需要「客户台账」，不需要「CRM 产品」**：把 `buyers/orders/payments/licenses/invoices/refunds` 建在自建商业服务 DB 里；0–50 人、单产品线时，专业 CRM 的销售流程价值 < 采购/实施/合规成本。
2. **【P0｜架构】license 记录必须放自建核心**：`licenses` 表 + 订单/支付外键是唯一事实源；第三方 license SaaS 只能做 P2 的「查看/门户」，绝不能做主库（数据出境、停服、无法开中国发票、订单与授权被切成两段）。
3. **【P0｜自建】离线 Ed25519 授权继续自建**：5–7 人日、0 订阅费；Keygen 起点 ¥665/月只买到云端许可 API，离线签发/订单绑定/发票/后台仍要自己写——自建更便宜也更干净。
4. **【P0｜支付】用「对公转账 + 人工签发」过渡，不提前收款**：零开发、合规；后台补「人工标记已付（二次确认 + 审计）」即可；**明确不做**个人收款码、不做 Ping++/虎皮椒类二次清算聚合。
5. **【P1｜支付】主力通道只做微信 + 支付宝直连**：0.6% 级 vs MoR 5%–11%，**便宜 8–18 倍**，能开中国增值税发票、主体一致、用户体验最好；回调验签/金额核对/幂等/对账是不可省的开发点（见 payment-invoice §8）。
6. **【P1｜发票】电子发票先买 API 不自建**：诺诺/高灯/百望均未公开报价（需商务谈，按张计费推断 ¥0.1–1/张 + 商户费）；用明道云加购价（¥199/商户/月、¥999/年、税号 ¥1,500/年）做比价锚点；专票保留人工审核。
7. **【P1｜CRM】优先低代码而非专业 CRM**：明道云 Standard ¥14,900/年 / 简道云标准版 ¥8,000 起/年即可搭「客户/订单/续费/发票」应用；先试用，**不要 P0 直接签纷享销客/销售易**（未公开报价、实施重）。
8. **【P1｜合同】电子合同按需买**：e签宝/法大大均未公开价、按份/套餐；只有团队/机构合同才需要，P0 用 PDF + 盖章 + 邮件/快递，法务审阅不能省。
9. **【P2｜license SaaS】只在两种情况下考虑 Keygen/Cryptlex/LicenseSpring**：① 产品线 >1、需要自服务门户/多语言 SDK；② 海外客户需要云端激活。届时优先 Keygen Std1（$99/月，≈¥665/月）或 LicenseGate 自托管；**LimeLM/Licentric 不建议**（数据/合规/成熟度）。
10. **【P2｜海外】Paddle/Lemon Squeezy 只做外币/海外补充**：中国内地主体资格需注册时确认（Paddle 官方「支持国家」是买方清单；LS 支持清单未取得静态文本、第三方称受限）；它们开境外发票，**不能替代中国增值税发票**；Gumroad 10%+$0.50 费率过高，仅可做试验。
11. **【横向｜合规】客户数据只放境内**：手机号/邮箱/发票信息属个人信息（PIPL），P0 全部落在四川主体境内服务器；**P0 不引入任何需要上传客户数据的境外 SaaS**；日志脱敏、保存期限、隐私政策、发票信息权限控制按 payment-invoice §12 执行。
12. **【横向｜预算】P0 现金支出接近 0**：自建 ≈15–27 人日（推断 ¥1.6–4.0 万一次性）+ 0 SaaS；P1 增量约 ¥1–3 万/年（云开票按张 + CRM-lite ¥0–1.5 万/年）；P2 视海外/规模化再开 SaaS 预算。**先把「订单-支付-授权-发票-对账」跑通，再谈 CRM。**
