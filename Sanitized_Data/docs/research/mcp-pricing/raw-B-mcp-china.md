## 3 结论：MCP 该不该单独定价？哪个档更合适？

### 3.1 国内 MCP/Agent 的付费现实（三条硬事实）

1. **MCP 服务本身在国内基本不单独收费**：阿里云百炼、腾讯云 MCP 广场、百度千帆、魔搭 MCP 广场，四家的 MCP 托管/云资源都是"免费"作为生态默认（第 14–17 条）。收费发生在两个位置——**模型 token** 与 **MCP/工具调用次数或运行时长**（第 13、18 条：0.03 元/次、0.5 元/小时、0.01 元/次）。
2. **"AI 能力"正在快速通缩成免费**：腾讯元宝把 Agent 全能力免费（第 7 条），而豆包把 Agent 类能力锁进 68/200/500 元三档（第 6 条）。同一时期同城两巨头做相反选择，说明**纯 Agent 能力已难以单独收费**。
3. **付费意愿真实存在但转化率不高**：56.1% 愿付费、仅 23.4% 实际付费（第 24 条）。愿意付钱的理由集中在"更精准/更高质量"（80.8%）与"更专业的领域知识"（65.7%）——**正好是"合规脱敏 + 可还原 + 审计"这类垂直专业价值的卖点，而不是"能接 MCP"这个技术卖点**。

| **¥999 买断** | 相当于 2 年专业版；对比单套企业脱敏软件 18.8 万几乎可忽略 | **保留**：本地工具用户对"一次买断、不联网、不再付"接受度高；建议买断**不含跨大版本升级**（v2.x 需补差），否则长期收入被截断 |
| **¥1,999/年/5 席（≈400 元/席/年）** | CodeBuddy 企业 2,376 元/席·年、Qoder Teams 1,188 / 企业 1,788 / VPC 2,388 元/席·年 | **偏低，可上探**：400 元/席·年只有 CodeBuddy 企业版 1/6；但 5 席起售对 2–10 人小所/诊所/代账公司很友好，建议**保留 1,999 作为最小可买单元**，另设 8–10 席的 ¥3,600–¥4,500 档 |

### 3.3 「MCP 单独定价」有没有空间？

**结论：不建议做独立 SKU，但建议做"调用/席位分级"的二级计费。**

- 反证：国内四家 MCP 平台都把 MCP 托管免费（第 14–17 条），**"为 MCP 接入本身付费"没有市场参照**；
- 正证：真正被计费的是**调用量**（0.03 元/次、0.5 元/小时、0.01 元/次）。数据隐站的 MCP 是本机 stdio，**没有云端调用成本**，按次收费既无成本依据、也容易被用户拿"元宝免费"来对标；
- 折中：**MCP 作为专业版功能位（current plan 正确）**，把它拆成"能力分级"——免费版不给 MCP；专业版给"每日 N 次/单文件 20 页"；团队版给"批量 + 审计导出 + 团队规则包"；机构版给"私有化 + 自定义 pack + API"。
- **唯一值得单独卖的 MCP 衍生品**：面向律所/医院信息科的"脱敏 MCP 网关/私有化接入包"（含部署、白名单、审计对接），可按项目报价 ¥5,000–¥30,000——这一档才对得上企业采购习惯（对标第 23 条人月单价 2.67 万起）。

## 4 对数据隐站 MCP / 专业版定价的启示（10 条）

1. **¥499 专业版是同价位带里"最不刺眼"的定价**：它夹在福昕 480、用友好会计 498 与 Kimi 年付 468 / GLM Lite 588 之间，用户不会觉得"一个本地小工具凭什么 499"。可放心把 MCP 绑在这一档。
2. **早鸟 ¥299 要写清"到期恢复 499"**：国内 Coding Plan 普遍以"首月 7.9–8.91 元"做钩子但正价 40–200（第 11、12 条），说明低价引流是常态、但价格锚必须由正价承担。若早鸟口径模糊，后续涨价会重演 GLM 2026-02 "规则透明度不够"的致歉（见第 9 条第三方记录）。
3. **别把"MCP 能接 WorkBuddy/Codex/DSH"做成主卖点**：元宝把 Agent 全免费、豆包把 Agent 卖到 68 元/月（第 6、7 条）——"能接 Agent"是免费能力。主卖点必须是**"文件在本地脱敏后才交给 Agent"**这个合规事实，以及 15 工具/资源/prompts 带来的"可复核、可还原、可审计"。
4. **国内 MCP 生态的定价权在"调用侧"，本机 MCP 应把价值放在"配额分层"而非"按次收费"**：0.01–0.03 元/次的参照价（第 13、18 条）折算下来一个律师一年用 1,000 次才 10–30 元，远低于 ¥499；按次收费既收不到钱，又会削弱专业版价值。建议专业版给足额度（如每日 50 次/不限页数），把差异做在**批量、审计导出、自定义规则包**上。
5. **团队版 ¥1,999/5 席严重低于市场企业席位价，是"可上探"信号**：CodeBuddy 企业 2,376 元/席·年、Qoder VPC 2,388 元/席·年（第 2、5 条），数据隐站仅 400 元/席·年。建议保留 1,999 作为"3–5 人小团队最小包"，同时新增 10 席档（¥3,600–¥4,500）承接小律所/诊所/代账公司，别让"5 席 1,999"成为唯一认知。
6. **机构版 ¥3.88 万起的定价安全，但交付物必须对齐采购语言**：企业比价对象是"单套脱敏软件 18.8–42.9 万、加固项目 54.5 万"（第 20–22 条）。3.88 万在采购眼里是"轻量工具"，所以要主动提供**私有化部署清单、规则包定制、审计导出样例、个保法/去标识化免责话术、发票与合同模板**——把"便宜"解释成"轻量+本地"而非"功能少"。
7. **目标人群的"个人已用 AI、机构未采购"是最大机会窗口**：律师 96% 个人在用、律所常规化仅 28%、47% 两年内要上 AI 战略（第 25 条）；医生 71% 在用（第 26 条）；财会 92% 企业已用（§1.5 补充）。**先卖个人/小团队（¥299–¥1,999），等律所/医院 2027 年预算周期再卖机构版**，别一开始就投入机构销售的获客成本。
8. **付费转化率 23.4% 意味着"免费额度"必须够痛才有效**：56.1% 愿付费但只有 23.4% 真付费（第 24 条）。当前免费版 3 份/天、20 页/份的设置偏宽松（脱敏 3 份文件通常不够一份合同+一份病历+一份对账单的完整工作流），建议**免费版限制"份数"而非"页数"**，让用户在第一周就撞墙。
9. **"可还原 + 不可还原双出口"是国内少有的差异化，值得写进价格页**：付费意愿调研里"更专业的领域知识"（65.7%）与"更精准更高质量"（80.8%）排前二（第 24 条），恰好对应"换名可还原给 AI / 涂黑不可还原给人看"这套双出口；这比"支持 MCP"更能解释 ¥499 为什么值。
10. **风险：豆包 68 元/月 + 元宝免费正在把"AI 付费"的心理价位往下压**：一年内外用户对"AI 该花多少钱"的锚可能从 199 掉到 68。对策是**把数据隐站放进"专业软件"货架而不是"AI 订阅"货架**——对标福昕 480/年、用友好会计 498–2,998/年、企业脱敏 18.8 万/套，而不是对标豆包/元宝。价格页文案应出现"专业版软件"而非"AI 会员"。
