# v1.3.3 · 上游质量 + 一致性修复版（2026-10-30）

> 正式版（收费门禁开启，`BUILD_ID=20261030-consistency`）。
> 本版基于两轮端到端测试（脱敏 → 盲读回件 → 回件还原 → 与原文对照），
> 修复上游检测/归并/伪值一致性，并修掉一个 PDF 还原字体缺陷。
> 承继 v1.3.2 的回件还原全部修复。

## 一、上游质量护栏（P0）

1. **归并过合并修复**：法院/学校/公司等不同机构不再因共享行政区前缀被并成
   同一假值；纯行政区 core、跨类别、超大簇（ORG>4、ADDRESS>5）不自动归并，
   转人工复核。新增「映射一致性检查」：任务完成/导出/还原时提示跨类别归并，
   可配置 `YINZHAN_MAPPING_GUARD=block` 阻断 AI 导出。
2. **实体质量闸门**：默认 enforce，只过滤高精度垃圾实体（印章词/动作词/句子
   片段/含“的”的伪机构），身份证/账号/银行等隐私关键类型永不自动丢；
   `YINZHAN_ENTITY_QUALITY=shadow|off` 可回退。

## 二、伪值一致性（P1-1）

1. **身份证**：按文档年龄/性别 + 入院/就诊等事件日期推导假生日；D12 实测
   假身份证在入院日 2025-03-17 恰好 67 岁、女、校验位合法。
2. **同值标签归一**：`住院号：…` 与 `住院号 …` 合并为同一实体，AI 视图不再
   出现同一住院号两个假值。
3. **固话**：保留原区号（只换本地号），与保留的地址城市一致。
4. **统一社会信用代码**：保留前 8 位地区码，只换组织机构代码段并重算校验位。

## 三、PDF 阅读顺序与还原字体（P1-2 阶段 1）

- AI 视图 PDF 的替换文字按页面视觉顺序（y,x）插入；D01 实测 raw 文本顺序已
  与版面一致，减少「按文本顺序抄错字段」。
- 修复：回件 PDF 自带 `china-s` 子集字体时，还原真值抽取为 `\x00`；现注册
  独立系统 CJK 字体并 `subset_fonts()`，D08 原值恢复 14/14、文件约 114 KB
  （修复前 12.5 MB）。

## 六、已知边界

- 涂黑区域/图片内文字/AI 改写或重算/编造的内容不可还原；
- AI 基于假值的推算备注（如“由假身份证推生日”）还原后可能过期，需人工核对；
- PDF 长真值会缩字、版式可能轻微位移；空格在抽取层可能表现为 NBSP；
- 多证件文档暂不套用单文档年龄/性别一致性（安全回退随机）；
- 安装包未代码签名，Windows SmartScreen 可能提示“未知发布者”；
- 既有映射库中历史 job 若已产生过合并，还原报告会提示，需人工核对。
