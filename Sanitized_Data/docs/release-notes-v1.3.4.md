# 数据隐站 v1.3.4 发布说明（首次带一键更新）

> 版本：**v1.3.4** · 2026-10-31
> 重点：加入客户端一键更新（检查 → 下载 → 校验 → 关闭 → 替换 → 重启），不静默安装。

## 一、本版新增

### 一键更新
- 启动后自动检查一次 CKA `/updates/latest.json`；
- 有新版本弹窗提示；
- 用户点「立即更新」才下载；
- 下载后校验大小 + SHA-256；
- 用户点「安装并重启」后关闭旧程序、替换绿色版目录、启动新版；
- 「稍后」24 小时内不再自动提示；
- 顶栏「检查更新」可手动检查。

### 更新安全
- 只接受 HTTP/HTTPS 清单；
- SHA-256 不匹配直接拒绝，不执行；
- 不覆盖用户数据目录；
- 更新 helper 失败会尝试重启旧程序并写 `updates/update.log`。

## 二、更新链路前提

1. CKA 必须发布 `latest.json`（包含 `windows_portable` 资产）；
2. 用户必须已经安装 **v1.3.4**（旧版 v1.3.3 没有 updater，需要手动装一次）；
3. v1.3.4 之后才能通过 updater 升级到 v1.3.5+。

## 三、已知限制

1. **Inno 安装器当前在部分机器启动失败**：本版首次安装请用绿色版/一键安装 `.cmd`；updater 走绿色版自替换，不依赖 Inno。
2. 更新包未代码签名，SmartScreen 可能提示；按既定决策后续补签。
3. 自动检查更新会访问 CKA 清单（仅版本/资产元数据），文件处理仍全本地。
